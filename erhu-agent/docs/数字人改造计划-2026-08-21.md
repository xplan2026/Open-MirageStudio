## 一、背景与目标

### 现状
- 二虎 MV 目前为**静态图片 Ken Burns 幻灯片**（`render.js`），无动态人物、无口型同步
- `generate-video.js` 已封装智谱 CogVideoX i2v（准数字人，无真正对口型）
- 历史生成的二虎形象图（`assets/erhu_*.jpg`）**偏向韩国人/日本人**，与预期不符

### 目标
1. **二虎形象重塑为西藏男性**（写实风格，民族特征鲜明）
2. **接入阿里云百炼 wan2.2-s2v 数字人对口型 API**：单张形象图 + 纯人声音频 → 二虎对口型唱歌视频
3. **音轨分离**：从歌曲中提取纯人声轨（对口型模型要求去除背景音乐），复用 mvsep 在线服务
4. 改造 `render.js` 支持"对口型表演段 + 空镜段"混合编排，产出真正动态的二虎 MV

## 二、调研结论（2026-08-21）

### 2.1 wan2.2-s2v — 阿里云百炼数字人对口型 API ✅ 已确认

**用途**：输入 1 张人物图片 + 1 段人声音频 → 生成人物说话/唱歌的动态对口型视频。

| 项目 | 内容 |
|------|------|
| 模型名 | `wan2.2-s2v`（限华北2 北京地域） |
| 创建任务 | `POST https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/services/aigc/image2video/video-synthesis` |
| 认证 | `Authorization: Bearer $DASHSCOPE_API_KEY` + `X-DashScope-Async: enable` |
| 请求体 | `{"model":"wan2.2-s2v","input":{"image_url":"...","audio_url":"..."},"parameters":{"resolution":"480P"}}` |
| 图片要求 | jpg/jpeg/png/bmp/webp，宽高 [400,7000]，**需公网 URL**（暂支持本地 Base64？需实测） |
| 音频要求 | wav/mp3，<15MB，**时长 <20s**，需清晰人声、**去除背景音乐** |
| 查询任务 | `GET https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/tasks/{task_id}`（轮询 15s，耗时 5-10 分钟） |
| 任务状态 | PENDING/RUNNING/SUCCEEDED/FAILED |
| 计费 | 480P 0.5 元/秒，720P 0.9 元/秒；输出按成功视频秒数计费 |
| 限流 | RPS 5，同时处理任务 1 个；新用户免费额度 100 秒 |

**关键限制**：音频 ≤20s → 整首歌曲需**切段调用再拼接**（每段 10-20s）。

### 2.2 音轨分离 — mvsep 在线服务 ✅ 保留（唯一参考）

- **保留** `docs/reference/mvsep操作指南.md`：在线 API，无需本地 GPU，含真实 `api_token`，开发历史已使用成功
- **已删除**：`demucs-音轨分离工具调研.md`、`Spleeter-音轨分离工具调研.md`、`UVR-音轨分离工具调研.md`（本地工具调研，非必要）
- 用途：提取歌曲纯人声轨（vocal），作为 wan2.2-s2v 的 `audio_url` 输入

### 2.3 二虎形象 — 西藏男性

历史 CogView/文心一格生成的二虎形象偏向韩国/日本人（瓜子脸、韩式发型）。改为：

```

浓眉大眼，眼神坚毅而温暖，鼻梁挺直，嘴唇略厚，下颌硬朗。
黑色短发利落（藏式风格），或扎起的长发。
身穿藏式风格服装（藏袍/氆氇材质围巾/藏式衬衫），或现代简约 + 藏式配饰（绿松石、天珠）。
气质：高原民族的粗犷、质朴、温暖，如高原的牧民或民谣歌手。
背景：雪山、草原、经幡或高原自然光。
```

## 五、依赖与风险

| 依赖 | 说明 |
|------|------|
| DASHSCOPE_API_KEY | 阿里云百炼（华北2北京），**当前 .env 缺失**，需用户提供 ⚠️ |
| WorkspaceId | 阿里云百炼业务空间 ID，需用户提供 ⚠️ |
| 音频切段 | wan2.2-s2v 音频 ≤20s，需按歌词/乐句切段 |
| 公网图片 URL | 形象图需可公网访问（wan2.2-s2v 要求公网 URL，或实测 Base64 支持） |
| 成本 | 480P 0.5元/秒，一首 3 分钟歌约 90 元（仅对口型部分），需用户确认预算 |

### 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 形象图人物一致性不足 | 各段不像同一个人 | 固定同一张参考图作为所有 s2v 调用输入 |
| 视频段拼接跳变 | 观感差 | 段间加淡入淡出转场（FFmpeg xfade） |
| 切段产生不自然断句 | 口型对不上 | 按歌词行/乐句对齐切段（复用 render.js 歌词时序） |
| s2v 限流（同时1任务） | 生成慢 | 顺序提交，段间轮询串行 |
| 公网 URL 需求 | 无法直接传本地文件 | 实测 Base64；若不行需临时图床/OSS |
