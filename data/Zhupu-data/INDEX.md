## 关系子图

| 文件 | 格式 | 用途 |
|------|------|------|
| [跨家族联姻图.json](./graph/跨家族联姻图.json) | JSON | 机器可读的根状关系图（主根·米家直系长房 + 4侧根 + 根须层 + 世代深度表） |
| [跨家族联姻图.md](./graph/跨家族联姻图.md) | Markdown | 人类可读 + ASCII根状总览 + Mermaid 图 + 根须化规律（Agent 长期记忆文件） |

> `graph/` 目录是 Zhupu Manager Agent 的**长期记忆**——以米家主根为中心的关系快速索引，优化 LLM 缓存命中。

## 数据格式

完整目录结构：

```
Zhupu-data/
├── INDEX.md          # 本文件 — 家族索引
├── graph/            # 关系子图（长期记忆文件）
│   ├── 跨家族联姻图.json   # 跨家族婚姻边数据
│   └── 跨家族联姻图.md     # Mermaid 可视化 + 血缘推导
└── {家族名}/          # 每个家族独立目录
    ├── 族谱.json       # 核心数据（JSON 结构化）
    ├── 家训.md          # 家训文本（可选）
    └── export/          # 导出文件
        └── {家族名}.md  # Markdown 导出
```

> 详细数据结构定义见 `zhupu-manager-agent/knowledge-base/族谱数据结构规范.md`
