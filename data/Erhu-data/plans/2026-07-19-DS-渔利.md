# DS-渔利（自然语言提示词测试）

## 创作主题

以"渔翁垂钓"为古典意象，层层剥露网约车行业中平台与司机之间的生态关系。全篇不直斥"资本"，而借渔事隐喻，为千万网约车司机的真实处境发声。

## 歌词方向

- 核心策略：**引喻贯穿** — 用钓鱼的全过程（撒饵→下钩→争抢→收网→散场）映射网约车司机的日常
- 语言策略：第一段纯文言设境 → 桥接段半文半白过渡 → 副歌白话点题 → 第二段文白交融深化 → 退出段回归意象收束
- 情绪曲线：沉静（设境）→ 渐醒（过渡）→ 激越（副歌点题）→ 沉痛（深化）→ 空寂（收束）

## 音乐风格

古风民谣，带叙事感。参考风格：写实民谣 + 古典词牌韵味。二胡/吉他配器，节奏由缓至急再归缓。

## 测试目的

测试 ACE-Step1.5 API 对中文自然语言提示词的接受程度，对比 JSON 结构化 prompt 与自然语言 prompt 的效果差异。

## 测试结论

### 最终版本：v4（钓江秋_v4.mp3，3.9MB）

**完整度最高，基本可作为生产模板。**

#### 验证生效的控制机制

| 机制 | 方式 | 效果 |
|------|------|------|
| 段落结构 | `[Verse]`/`[Pre-Chorus]`/`[Chorus]`/`[Outro]` 英文标签 | ✅ 完整生效 |
| 间奏 | `[Interlude - erhu, 10s]` / `[Interlude, 10s]` | ✅ 段落间有器乐间隔 |
| 尾奏退场 | `[Instrumental - erhu solo, fade out, 10-15s]` | ✅ 二胡独奏渐弱退场 |
| 前奏 | `[Intro - short, 15s]` + caption 约束 | ⚠️ 部分生效，不完全精确 |
| 中文演唱 | caption 强约束 + 歌词纯净（无英文混入） | ✅ 全中文 |

#### 关键发现

1. **自然语言 > JSON prompt**：自然语言描述生成的音乐质量显著高于结构化 JSON
2. **段落标签必须英文**：`[Verse]`/`[Chorus]` 等被 ACE 原生支持，中文标签无效
3. **歌词不得混入英文**：括号内英文描述会被 ACE 当作歌词，导致整首英文演唱
4. **控制指令放 caption**：所有英文描述/约束放在 caption 中，歌词保持纯中文 + 结构标签
5. **前奏时长不可精确控制**：API 无独立 intro 时长参数，只能通过标签和 caption 软约束
6. **尾奏需 `[Instrumental]` 标签**：仅靠 `[Outro]` 唱完即止，需追加器乐标签实现退场旋律

#### 推荐工作流模板

```
固定中文歌词
  → 添加英文段落标签
  → 添加 [Interlude] 间奏标签
  → 添加 [Instrumental - fade out, 10-15s] 尾奏标签
  → caption 中英文描述风格/乐器/情绪/约束
  → content 中混入 vocal_language: zh / instrumental: false
  → 直传 ACE Chat Completions
```

#### 遗留问题

- 部分生僻文言词（螺厣、糠秕、银鲦）唱词含糊，可考虑用空格分隔音节辅助发音
- 前奏时长无法精确控制，ACE 对此约束遵循不稳定
- 尾奏实际时长可能略超目标，`10-15s` 范围标注比固定值更实际
