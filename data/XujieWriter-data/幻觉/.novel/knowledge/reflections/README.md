# 思考 (Reflections)

> 作者对时事与记忆中故事的不同角度的思考，可以不断丰富小说的内涵。

## 用途

此处存放创作过程中的**思想素材**——不一定是可用的故事片段，而是对世界的观察、对历史的反思、对人性的洞察。这些思考：

- 可能转化为角色的价值观或行为逻辑
- 可能成为某个情节的哲学底色
- 可能仅作为作者理解时代的辅助参考

## 收录标准

- 有一个明确的思考角度或观察结论
- 与小说的时代背景、主题、人物命运有关联
- 不追求结论正确——追求视角独特、发人深省

## 思考维度

| 维度 | 示例问题 |
|------|---------|
| **时代** | 某个历史事件对普通人的真实影响是什么？被主流叙事忽略的侧面有哪些？ |
| **人性** | 人在极端环境下的选择逻辑是什么？幸存者为何幸存？ |
| **家庭** | 家族传承的究竟是血脉、财产，还是某种命运模式？ |
| **知识** | 知识如何改变一个人的命运？知道更多真的会更好吗？（小说核心主题） |
| **记忆** | 记忆如何被重构？口述历史的可靠性边界在哪里？ |

## 文件命名规范

```
{日期}-{主题关键词}.md
```

示例：
- `2026-07-27-分家不公与个人堕落.md`
- `2026-07-28-第三代为何不再追问祖辈.md`
- `2026-08-01-知识焦虑的跨代传递.md`

## 思考模板

```markdown
# {思考标题}

- **日期**：{YYYY-MM-DD}
- **触发源**：{时事新闻 / 阅读笔记 / 记忆片段 / 对话启发}
- **关联主题**：{核心主题标签}

## 观察

{原始观察或事件描述}

## 思考

{多角度分析、质疑、联想}

## 小说映射

- 可能的章节/情节映射
- 可能的角色塑造影响

---

> 此目录为思想素材库，内容随思考不断积累，不定期回顾整合。
```
