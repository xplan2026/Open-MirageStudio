# 伪知识来源清单

> 本清单是《幻觉》情节描写的核心参考库。
> 每一类"伪知识来源"都是潜在的场景素材。
> **持续补充中**——每发现一种新的"伪知识传播模式"就添加到此处。

---

## 一、伪知识的传播链条模型

```
信息源头（制造者/误读者/算法推荐/AI 生成）
    ↓ 某人看到/听到/刷到，将"信息"当作"知识"接受
    ↓ 告诉身边人："书上说的""专家说的""网上看到的""AI 说的"
    ↓ 接收者同样将"信息"当作"知识"接受
    ↓ 继续传播……
    ↓
链条上每个人——在每一个环节——都在把未经审视的信息当作知识
```

**小说的核心场景**：展示这个链条的每一环——不是批判人们的"真诚"，而是呈现"信息被混淆为知识"如何自然而然地发生。根本问题不在于传播者的态度是否真诚，而在于信息与知识之间的边界被系统性地模糊了：权威的崩塌、算法的操控、AI 的幻觉。

## 四、典型情节场景库

### 场景 1：家庭餐桌上的伪知识接力

```
时间：1988 年，米丰 15 岁
场景：晚饭桌上
父亲："今天报纸上说，隔夜茶不能喝，致癌。"
母亲："是吗？那以后别喝了。"
米丰（内心）：报纸上说的就一定是真的吗？
第二天，母亲对邻居说："隔夜茶致癌，报纸上说的。"
```

### 场景 2：电视专家的"权威"认证

```
时间：1998 年，米丰 25 岁
场景：客厅看电视
电视专家："猪油含有大量饱和脂肪酸，是导致心脑血管疾病的元凶。
          建议国人用植物油替代猪油。"
母亲："听见没有？以后别吃猪油了。"
（从此家里再也没出现过猪油）
十年后，新的研究说：适量猪油有益健康。
母亲："那以前电视上说的是假的？"
```

### 场景 3：朋友圈的养生接力

```
时间：2015 年，米丰 42 岁
场景：家族微信群
大姨转发：《这十种食物是癌症克星！》
二舅转发：《央视曝光！这些东西千万别吃！》
母亲："你看看，这些东西都不能吃了。"
米丰点开文章，来源是一个不知名的养生号。
但全家族已经信了。
```

### 场景 4：AI 的自信谎言

```
时间：2023 年，米丰 50 岁
场景：办公室
同事："我用 AI 查了一下，XXX 事件是这样的……"
米丰："这个 AI 经常编造信息。"
同事："不可能吧，AI 怎么会说谎？"
米丰（内心）：又一个把 AI 当真理的人。
```
