# 零散桥段 (Fragments)

> 不断积累补充的故事情节片段，可结合时间线引用，丰富小说内容。

## 用途

此处存放创作过程中产生的**独立桥段、场景片段、对话构思、人物细节**等尚未归属具体章节的故事素材。这些片段：

- 可能在某个时间点被纳入具体章节
- 可能作为子情节或旁支独立发展
- 可能仅用作人物性格塑造的参考

## 收录标准

- 有完整的故事性——即使是 200 字的片段，也要有起承转合
- 明确标注可嵌入的时间窗口（年代/人物年龄/卷章）
- 注明来源（灵感来源、现实原型、关联事件）

## 文件命名规范

```
{年代}-{关键词}.md
```

示例：
- `1944-码头送别.md`
- `1950-筒子楼第一个春节.md`
- `1985-米南生第一次读报.md`

## 片段模板

```markdown
# {片段标题}

- **时间窗口**：{年代 / 人物年龄 / 卷章}
- **涉及人物**：{角色列表}
- **类型**：{场景 / 对话 / 心理 / 事件}

## 内容

{片段正文}

## 嵌入建议

- 可嵌入章节：{卷X第Y章}
- 与主线关系：{补充 / 伏笔 / 独立彩蛋}

## 来源

{灵感来源、现实原型等}
```

---

> 此目录为创作素材库，内容随创作过程不断积累，不作为正式章节。
