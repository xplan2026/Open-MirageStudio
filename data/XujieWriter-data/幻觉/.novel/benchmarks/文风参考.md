# 《幻觉》文风参考

> 综合 6 本对标书的文风特征，确定本作文风基调
> 日更前必读此文件

---

## 一、文风定位

**基调**：克制内省 + 年代质感 + 日常中的思辨

本作不是爽文，不以"打脸""逆袭"为爽点来源。文风应在以下三个维度之间找到平衡：

```
克制的文学性 ← 本作 → 通俗的叙事流
     ↑                    ↑
《克莱因壶》          《我们生活在南京》
《你当像鸟飞往你的山》  《乔家的儿女》
```

---

## 二、句长分布

| 类型 | 占比 | 适用场景 |
|------|------|---------|
| 短句（<15字） | 35% | 童年视角、关键认知转折、情感冲击 |
| 中句（15-30字） | 50% | 日常叙事、年代细节描写 |
| 长句（>30字） | 15% | 内心思辨、知识体系反思、环境渲染 |

**参考**：
- 《克莱因壶》短句占比 40%，用于悬疑紧张感
- 《你当像鸟飞往你的山》中长句占比较高，用于内省反思
- 本作取中间值，童年阶段短句偏多，中年阶段适当增加长句

---

## 三、标点运用

| 标点 | 用法 |
|------|------|
| 逗号 | 密度适中，一句话 2-3 个停顿，保持口语感 |
| 句号 | 干脆利落，段落结尾不拖沓 |
| 感叹号 | **极度克制**，仅在情感真正爆发时使用（全书不超过 20 处） |
| 问号 | 用于米丰的内心独白——"他真的知道吗？""这些知识，有多少是真的？" |
| 省略号 | 克制使用，用于欲言又止的对话和记忆的模糊处 |
| 破折号 | 用于思维的跳跃和打断 |

---

## 四、对话特征

| 维度 | 规范 |
|------|------|
| 对话占比 | 约 45-55%（高于纯文学，低于纯对话体网文） |
| 对话标签 | 多用"说""问""道"，少用复杂副词（"愤怒地说"→ 用动作替代） |
| 潜台词 | **高频使用**——家人对话中大量言外之意，尤其是米丰觉醒后与家人的交流 |
| 对话节奏 | 童年：天真多问；少年：叛逆反问；中年：克制停顿 |
| 方言 | 可少量使用增加年代质感，但需控制在 5% 以下，不影响阅读流畅 |

**参考**：
- 《我们生活在南京》：对话自然口语化，时代感通过用词而非方言实现
- 《繁花》：沪语书写实验，但不适用于网文场景

---

## 五、情绪节奏

| 维度 | 设计 |
|------|------|
| 情绪周期 | 约 5 章一个情绪起伏循环 |
| 紧张-松弛 | 认知冲突（紧张）→ 日常互动（松弛）→ 新认知裂缝（紧张） |
| 情绪峰值 | 每卷末设置认知觉醒的高光时刻 |
| 低谷处理 | 用家庭日常、年代生活细节填充，不空洞 |
| 整体曲线 | 先扬（童年信任）→ 渐抑（启蒙困惑）→ 低谷（信息焦虑）→ 微升（和解提醒） |

**核心原则**：情绪不直给，用动作和细节暗示。米丰的"觉醒"不是喊出来的，是做出来的。

---

## 六、描写风格

| 维度 | 规范 |
|------|------|
| 五感描写 | 重点使用视觉 + 听觉 + 嗅觉（年代感的三个核心感官） |
| 白描 vs 渲染 | 日常场景 80% 白描，关键认知转折 20% 渲染 |
| 内心独白 | 仅用于认知转折的关键节点，每章不超过 2 段 |
| 环境描写 | 融入叙事，不单独成段——"教室墙上的标语褪了色"而非"这是1979年的教室" |

**参考**：
- 《乔家的儿女》：白描式年代细节，真实而不煽情
- 《你当像鸟飞往你的山》：内心独白精准克制，情感靠行动承载

---

## 七、叙事视角

| 维度 | 规范 |
|------|------|
| 人称 | 第三人称有限视角（以米丰的感知为边界） |
| 信息控制 | **读者知道的 ≤ 米丰知道的**（"大梦一场"叙事的核心纪律） |
| 时间跳跃 | 关键年份深度写，过渡年份用蒙太奇段落 |
| 记忆碎片 | 米丰的"先知记忆"偶尔以斜体或独立段落呈现，与当前叙事形成对照 |

---

## 八、日更纪律

每日写作前，回顾以下要点：

1. ✅ 保持短句节奏，不要连续使用 3 个以上长句
2. ✅ 对话要口语化，不同年代用不同时代的语言
3. ✅ 情绪不要直给——"他感到愤怒"→ 写他攥紧的拳头
4. ✅ 年代细节融入叙事，不要罗列展览
5. ✅ 每章至少一个"认知裂缝"的微小暗示
6. ✅ 不让米丰变成说教者——他困惑，他不懂，他也在寻找答案
