# 米丰 — 主时间线

> 本文档是米丰一生的完整时间线，是角色建档、大纲编排、章节写作的核心参考。
> **持续细化中**——每个阶段都可以进一步展开为详细的场景和故事。
>
> **核心精神对照**：父母的一生踏实而显出真实；米丰的一生丰富却像浪一样虚幻而漂浮。这不单是对人物的设定，也是对这个时代的描绘——喧嚣而人心浮动，信息爆炸而盲从。

## 一、家庭环境

### 父亲 — 米老师

| 时间段 | 事件 |
|--------|------|
| 1961-1969 | 在云南某部队当兵 |
| 1969 | 转业回到原单位（江城造纸厂），被厂里安排到教师进修学校学习三年 |
| 1971 | 与米丰母亲结婚 |
| 1972-1975 | 回厂里子弟中学担任英语老师、班主任（只带了一届学生——1960年前后出生年龄段） |
| 1972-1975 | 这届学生深受父亲影响，对父亲的敬爱持续终生——后期有大量学生与父亲之间的互动故事 |
| 1976-1978 | 调任厂教育科科长 |
| 1978-2003 | 历任：厂6车间书记 → 厂储运科科长（后随厂改革升级为处长） |
| 2003 | 退休 |

**人物特征**：
- 常被人尊称：米老师 / 米书记 / 米老哥 / 老米
- 退休后的主要娱乐：学生/同事聚会、钓鱼、打麻将（一周 2~3 场）
- 性格：正直、受学生爱戴、有威信但不专制
- **小说中的角色定位**：第一代"知识权威"的代表——父亲作为教师，本身就是"知识传播者"。但父亲传播的知识可靠吗？这将是米丰觉醒的第一个触点。

> **信用卡逾期事件是米丰经济走下坡路的核心转折点**：
> - 这不是米丰的主观过失，而是"信息断层"造成的——他的还款能力没问题，但他不知道要还款
> - 公司收回手机号是合规操作，银行按预留号码通知是标准流程，每一步都是"对的"，但合在一起造成了灾难
> - 这就是"系统之恶"：没有人在做错事，但伤害确实发生了
