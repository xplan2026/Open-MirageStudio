### 父亲 — 米南生

| 属性 | 内容 |
|------|------|
| 姓名 | 米南生 |
| 出生 | 1943年5月，四川潼南 |
| 身高 | 168cm |
| 身份 | 退伍军人（8年）→ 英语教师 → 教育科科长 → 车间书记 → 储运处处长 |
| 退休 | 2003年 |
| 出场 | 第一卷 ch04（米丰8岁）→ 全卷 |
| 定位 | **"踏实"人生的代表**。第一代"知识权威"——教师+干部身份，是米丰认知觉醒的第一个参照系 |
| 独立档案 | `米南生.md` |

**性格特征**：
- 稳健、沉默、不啰嗦——八年部队生涯磨出的气质
- 喜欢用提问引导对方思考，而非直接给答案
- 尊称：米老师 / 米书记 / 米老哥 / 老米

**在小说中的功能**：
- 第一个让米丰意识到"权威也会错"的人（ch04：报纸上的地名错误）
- "踏实人生"的象征——一条直线的职业生涯，对比米丰波浪般的职业跳跃
- 两次关键提问（1988年"竞争"、2009年"50岁"），是米丰认知起飞的两个助推点

**关键场景**：
- ch04：米丰指出报纸上的地名错误，父亲说"可能是印刷错误"
- ch07：父亲练气功，对着大树"发功"
- 1988年3月：米丰初三早恋，父亲问"学习的目的是什么？"——答："是为了与同龄人竞争"
- 2009年春节：米丰巨亏，父亲问"你觉得你自己50岁的时候会成为一个什么样的人？"——往远看
- 第六卷：2011年父亲卖旧房分钱给两兄弟，搬进米丰的还建房

### 母亲 — 杨常玉

| 属性 | 内容 |
|------|------|
| 姓名 | 杨常玉 |
| 出生 | 1947 年 10 月 |
| 去世 | 2022 年 4 月（享年 74 岁） |
| 身份 | 务农，持家 |
| 户籍 | 农业户口 → 2008 年征地拆迁转农转非 |
| 出场 | 第一卷 ch01（1979年带米丰报名）→ 第六卷（2022年去世） |
| 定位 | **"经验知识"的代表**。文化不高，但勤劳善良正直——"绝不愿亏欠别人" |
| 独立档案 | `杨常玉.md` |

**性格特征**：
- 勤劳、善良、正直，一辈子不亏欠别人
- 对任何被主流渠道传播的"知识"无条件信任——书的、电视的、邻居的、群里的——信任本身是真诚的
- 固执——相信的东西会用最朴素的方式坚持，比如固执地要喂儿子吃泡豇豆
- 不擅长表达情感，身体动作比语言诚实
- 口头禅："××说的，还能有假？"

**知识态度演变**：书（绝对相信）→ 口传（照单全收）→ 转述（信息变形而不自知）→ 电视（换个媒介继续信）→ 微信群（老年目标受众）

**在小说中的功能**：
- 伪知识传播链条上最真实、最纯粹的一环——不是制造者，是真诚的接收者和传播者
- 母亲的知识态度演变反映了中国媒介变化的完整时间线
- 母子关系是全书最细腻的情感线——一根泡豇豆推开，一个搂肩膀拉回

**关键场景**：
- ch01：带米丰报名小学，说出"书上写的还能有假？"——主题种子
- ch03：认真记下邻居说的偏方——"张大妈说的，肯定管用"
- ch08：转述亲戚的信，信息在转述中变形——"差不多是这个意思"
- 约1985-1986年：泡豇豆事件——米丰含住又吐掉，母亲呆住了，米丰当场后悔。**全书最残酷也最真实的母子场景**
- 约成年后：搂肩膀——米丰主动搂住母亲肩膀，母亲愣一秒后激动，修复了多年的疏离
- ch23（1995年）：因电视专家说"猪油有害"，从此家里不再用猪油
- 2022年4月23日（去世前5天）：母亲小声说想开车，米丰答应带她去试——再也未能兑现
- 2022年4月28日：买菜上台阶摔倒，脑干脱离脊柱——米丰为她做了最后两个决定（开颅手术、放弃治疗）
- 2022年：丧事——弟弟要去市里大殡仪馆，米丰说服他在本区办——"来的人多，才算真的风光"

### 米旺 — 弟弟

| 属性 | 内容 |
|------|------|
| 身份 | 米丰的弟弟 |
| 出生 | 1975年5月（比米丰小2岁） |
| 出场 | 第一卷（童年）→ 全卷 |
| 定位 | **"接受型人格"代表**——从不质疑权威，是母亲认知模式的延续。与米丰形成"觉醒者 vs 未觉醒者"的对照 |
| 独立档案 | `米旺.md` |

**人生轨迹**：高中毕业 → 江城造纸厂（父亲的关系）→ 国企改革后转入民营企业仓库管理 → 平稳的蓝领/技工生涯

**性格特征**：
- 本分、安于现状、不折腾
- 对米丰的态度：既佩服又困惑——"你想那么多干嘛？"
- 知识态度：从不质疑——报纸对就对、电视对就对、群里说对就对

**在小说中的功能**：
- "接受型人格"的代表——伪知识传播链上最大众的那一环
- 兄弟关系的核心情感不是冲突，是"越来越远"——从童年一起爬树到成年后只能说天气
- 证明"觉醒不是必然的"——同样的环境、同样的信息，有人质疑，有人接受

| 属性 | 内容 |

| 出场 | 第三卷（1998年以"女朋友"身份）→ 第六卷 |
| 定位 | **亲密关系中的认知同步/不同步** |
| 独立档案 | `妻子.md` ✅ |

**关键事件**：
- 1998：与米丰一起开练歌房
- 1999.9：结婚
- 2001：女儿出生
- 2006：对"百度百科"的信任（B线核心场景，与母亲"书上写的还能有假"代际对照）
- 2008：儿子出生
- 2008-2011：陪伴米丰经历青岛饭店巨亏
- 2020：做直销（不会做，由米丰接替，伤了人脉）
- 2020-2023：与米丰共度疫情

**性格特征**：
- 务实、能扛——练歌房→巨亏→疫情，是并肩的人而非被保护的人
- 知识态度：信任百度百科、微信群——与母亲杨常玉的信任模式一脉相承，只是媒介变了
- 与米丰的关系：情感上同舟共济，认知上始终保持距离——她不理解米丰的"觉醒"但她爱他

**在小说中的功能**：
- 米丰最亲密的人，也是"伪知识传播链"上最近的一环——他是米丰最难面对的镜子
- 直销事件：米丰替妻子做直销→自己成为伪知识传播者——这是米丰觉醒的关键节点之一
- 与母亲（杨常玉）、米旺构成"伪知识接收者"三角映照——三代人、三种媒介、同一套信任模式

## 八、跨卷人物

### 父亲的学生（群体）

| 属性 | 内容 |
|------|------|
| 身份 | 父亲1972-1975年在子弟中学带的那一届学生（1960年前后出生） |
| 出场 | 全卷（以回忆/互动形式出现） |
| 定位 | **"知识权威"的另一面**——父亲传播的知识是否可靠？但学生对父亲的爱戴是真实的。这构成了一个对照：知识可能不可靠，但情感可以是真实的。 |

**在小说中的功能**：
- 证明父亲的"踏实人生"是有价值的——即使他传播的知识有误，他的人格影响了学生
- 后期与父亲的大量互动故事（待细化）
- 可以作为米丰反思的参照：如果知识不可靠，那什么才是可靠的？（情感？人格？）
