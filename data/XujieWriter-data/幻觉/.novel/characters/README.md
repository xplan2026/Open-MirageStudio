# 角色档案目录

> **结构变更**：2026-08-20 起按"角色类别"划分子目录（配合多家族镜头切换创作模式）

## 目录结构

```
characters/
├── 姻亲/          # ★ 各家族（姻亲）内人物 — 米家/李家/杨家/何家/于家等
│   ├── 人物表.md       # 家族人物总览表
│   ├── 米丰.md
│   ├── 米南生.md
│   ├── 杨常玉.md
│   └── ...
├── 社会关系/      # ★ 几大家族以外的重要社会关系（重要角色）
│   ├── 模板.md
│   └── {角色名}.md
└── README.md
```

## 划分规则

| 类别 | 目录 | 收录对象 |
|------|------|---------|
| **姻亲** | `姻亲/` | 各家族谱内人物（有族谱归属），如米家米福云、李家李维贞、杨家杨常玉 |
| **社会关系** | `社会关系/` | 家族谱外但与故事密切相关的重要角色，如田维城（地下交通员）、曾绾（米巧儿之子，曾氏） |

## 说明

- 家族人物若增加独立角色文件，**一律放入 `姻亲/` 目录**
- 社会关系角色由创作者提供素材，按 `社会关系/模板.md` 整理成独立文档
- 角色档案文件格式遵循 `ai-fiction-writer/纯净版skill/novel-character/SKILL.md` 规范
