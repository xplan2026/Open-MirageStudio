# 社会关系角色档案

> 收录：**几大家族以外的重要社会关系（重要角色）**——不属于任何家族族谱，但与多家族叙事紧密相关的关键人物。
>
> 如：田维城（中共地下交通员，代养米南生 1-6 岁）、曾绾（米巧儿之子，曾氏，米福云外甥兼玩伴）等。

## 使用说明

1. 创建角色档案前，先复制 `模板.md` 为 `{角色名}.md`
2. 按模板结构整理角色素材（素材由创作者提供）
3. 每个角色一个独立文档，命名 `{角色名}.md`
4. 素材不足的字段可标注"待补充"，但核心字段（身份定位/与各家族关系/叙事功能）必须填写

## 与姻亲角色的区别

| 类别 | 目录 | 特征 |
|------|------|------|
| 姻亲 | `姻亲/` | 有族谱归属（米家/李家/杨家/何家/于家） |
| 社会关系 | `社会关系/` | 家族谱外，但与故事主线、多家族叙事紧密相关 |

> 判定：该角色能否在某个家族 `族谱.json` 中找到关系节点？能 → 姻亲；不能但重要 → 社会关系。
