# 《幻觉》创作背景

> 创建时间: 2026-07-15  
> 最后更新: 2026-07-16（v10 成功！独立 .txt 歌词 + 两步流程 + 人工审阅 = 接近发布级质量）

## 一、歌曲立意

我们始终处于知识来源混乱的时代。

曾经以学校课本为权威，后来以印刷出版物为准，再后来依赖专家言论和搜索引擎。AI 浪潮袭来后，越来越多的人通过 AI 获取未知知识——但这带来了新的问题：

- **课本知识**不可全信，部分已经过时失效
- **印刷品知识**日渐稀少
- **网络知识**互相矛盾，无从分辨真伪

AI 的回答有两个核心信任障碍：

1. **AI 幻觉** — 自信地胡说八道
2. **人为灌输的假知识** — 被有意植入的错误信息

尽管无奈，但我们已经觉醒。唯一能做的，是坚持求索的觉悟：多方求证，不断增长分辨真伪的能力。

## 二、歌词设计

| 维度 | 设计方向 |
|------|----------|
| **风格** | 草原诗 — 辽阔、苍凉、深沉 |
| **表达方式** | 直白 + 类比，可吟可唱 |
| **修辞要求** | 对仗工整、韵律统一，但可灵活变化 |
| **核心意象** | 风、草原、马头琴、呼麦、沙粒、鹰、河流 |

## 三、音乐方向

由 ACE Step1.5 自适应生成，不指定 BPM/调式/和弦走向，仅描述风格氛围与乐器配置：

- 蒙古传统乐器：马头琴（morin khuur）、呼麦（khoomei）
- 现代乐器：木吉他、鼓
- 人声：低沉沙哑男声，叙事性唱法
- 氛围：辽阔、沉思、坚韧

### 核心发现

1. **ACE Chat Completions 接口存在"英文暖场"倾向** — 即使 prompt 中英文极少，ACE 仍可能在前 30-50 秒生成英文内容，之后才切换到中文。这不是 prompt 英文量的问题。
2. **v10 工作流成功的关键要素**（已验证可稳定复现）：
   - **独立 `.txt` 歌词文件** — 含 ACE 标准结构标注 `[Verse 1]`/`[Chorus]`/`[Bridge]`/`[Outro]`
   - **两步流程** — 歌词生成 → 人工审阅 → 音乐生成，分离关注点
   - **强约束 content** — `LYRICS (Chinese, MUST sing exactly these in Mandarin, do NOT translate):`
   - **最简 prompt** — caption_en 只描述风格/乐器/情绪，不超过 100 字符英文
   - **足够长的歌词** — 417 字符，30 行，6 段结构
3. **结构标注不是英文演唱的原因** — v8 的英文问题来自 prompt 英文量过大（~350 字），而非结构标注。ACE 原生支持 `[Verse]`/`[Chorus]` 标签。
4. **顶层 `lyrics` 参数不可用** — Chat Completions 接口不支持（返回 HTTP 504），`/release_task` 端点已下线（404）。
5. **同歌词多次生成输出稳定** — 两次生成文件大小差异仅 0.2%（3681KB vs 3673KB），质量可预期。
