# 镜头切换创作模式

> **定位**：长篇多家族史诗类小说的推荐创作模式。用于在同一时间线上，分别 + 同步描述**多个家族**的动态，并结合**几大家族以外的重要社会关系**（重要角色）展开叙事。
> **适用题材**：家族史诗、群像剧、多线叙事的年代文/历史文/都市文。
> **诞生背景**：原单线时间线叙事（仅围绕一个家族）在多家族族谱齐备后，无法承载多家族并行叙事 → 升级为镜头切换模式。

---

## 一、核心思想

**「时间轴是经线，家族线是纬线」**：

- 全书有一条**统一时间轴**（年/月/日），所有家族事件挂靠其上
- 每个家族是一条**叙事线**（镜头），各自推进各自的动态
- 镜头在家族线之间**切换**，呈现「同一时刻，不同家族各自发生什么」
- 在家族线之外，还有一条**社会关系线**（非家族谱内的重要角色），负责把各家族勾连起来、提供外部视角

```
时间轴 ──────────────────────────────────────────►
        ▲           ▲           ▲
        │           │           │
   米家线(镜头)   米家线       米家线
   李家线(镜头)   李家线       李家线
   杨家线(镜头)   杨家线       杨家线
   社会关系线    社会关系线    社会关系线
    (镜头)        (镜头)        (镜头)
```

## 二、叙事结构

### 2.1 三条轴线

| 轴线 | 内容 | 功能 |
|------|------|------|
| **家族线**（每个家族一条） | 该家族在时间轴上的动态：事件、人物成长、家族兴衰 | 主干叙事 |
| **社会关系线** | 家族谱外的重要角色（挚友/恩人/对手/见证者等）的视角与行动 | 勾连家族、外部视角、独立支线 |
| **时间轴** | 全书统一纪年，所有事件精确挂靠日期 | 经线，保证多线同步 |

### 2.2 镜头切换（Camera Switch）

每章由 **2~4 个镜头**（场景群）组成，镜头之间通过切换衔接：

| 切换类型 | 说明 | 示例 |
|---------|------|------|
| **并行切换** | 同一时刻，从 A 家族切到 B 家族（A 事件与 B 事件同时发生） | 米家张罗分家时，李家正在讨债 |
| **因果切换** | A 线的行动导致 B 线的反应 | 米家逃债 → 田维城连夜转移米南生 |
| **呼应切换** | A 线设置的信息/情感，在 B 线得到呼应 | 米南生入伍，李家儿子同日回城 |
| **悬念切换** | A 线留悬念 → 切 B 线 → 稍后回 A 线揭晓 | 米福云失踪 → 切李家线 → 再回揭示去向 |

### 2.3 镜头标记

细纲与正文中，每个镜头（场景群）需标记所属线：

```markdown
## 场景列表

1. **场景1（米家线）**：{场景名称}
2. **场景2（李家线）**：{场景名称}
3. **场景3（社会关系线）**：{场景名称}
```

正文 HTML 注释同步标注镜头归属：

```markdown
<!-- LOGIC: time=1916-03-15 09:15 | loc=米家大宅 | line=米家线 | present=米福云,米湘 -->
<!-- LOGIC: time=1916-03-15 09:15 | loc=李记当铺 | line=李家线 | present=李维贞之父 -->
```

## 三、多家族镜头切换大纲

### 3.1 大纲结构

```markdown
## 第 {N} 章：{章标题}（{故事日期范围}）

- **镜头序列**：{米家线 → 李家线 → 社会关系线}
- **时间对齐**：{本章所有镜头发生在同一时间跨度内，标注起点-终点}
- **POV**：{主镜头视角}
- **标签**：【{线A}】【镜头切换】【爽点】【钩子】

#### 镜头 1（米家线）{时间：HH:MM-HH:MM}
- {该家族本章动态：事件/冲突/转折}
- 出场角色：{角色列表}

#### 镜头 2（李家线）{时间：HH:MM-HH:MM}
- {该家族本章动态}
- 出场角色：{角色列表}

#### 镜头 3（社会关系线）{时间：HH:MM-HH:MM}
- {重要角色本章行动}
- 出场角色：{角色列表}
```

### 3.2 时间轴对齐表（每章/每卷）

卷首建立**时间轴对齐表**，标注同一时刻各家族的各自动态：

```markdown
| 时间 | 米家线 | 李家线 | 杨家线 | 何家线 | 于家线 | 社会关系线 |
|------|--------|--------|--------|--------|--------|-----------|
| 1916-03 | 分家被算 | 当铺扩张 | （未登场） | （未登场） | （未登场） | 田维城入川 |
| 1944-06 | 米湘逃债 | 收米家铺子 | （未登场） | （未登场） | （未登场） | 地下党接应 |
| 1961-09 | 南生参军 | 李维贞续弦 | 杨常玉归川 | （未登场） | （未登场） | 曾绾销声匿迹 |
```

> **规则**：同一时间点，最多 3 条线同时推进（超出则读者跟不上）；未登场的家族线在表中标注"未登场"，不可凭空跳线。

### 3.3 镜头切换节奏

| 范围 | 切换频度 | 原则 |
|------|---------|------|
| 单章 | 2~4 个镜头 | 每镜头约 800-1500 字，形成"短镜头快切"节奏 |
| 单卷 | 每 3-5 章至少覆盖 1 条新的家族线 | 保证多家族都有戏份 |
| 全书 | 各家族线按卷推进 | 遵循族谱关系网与跨家族联姻图（如有） |

### 3.4 社会关系线设计

社会关系角色（家族谱外）承担三个功能：

1. **勾连**：把互不相识的家族通过该角色连接（如地下交通员同时接触米家与李家）
2. **外部视角**：用局外人的眼睛看各家族（如账房先生见证米家衰败）
3. **独立支线**：自身也有完整的人物弧线（不只是工具人）

> 重要角色可能不是一次性配齐——当有新增社会关系角色时，**联动修改已有草稿**（在既有镜头中加入该角色的行动/视角，或在其出场章节前埋设伏笔），增加故事的生动与完整。

## 四、角色档案体系

### 4.1 目录分类

```
characters/
├── 姻亲/          # ★ 各家族谱内人物（有族谱归属）
│   ├── {家族A}/{角色名}.md 或 {角色名}.md
│   └── ...
├── 社会关系/      # ★ 家族谱外的重要角色
│   ├── 模板.md
│   └── {角色名}.md
└── README.md
```

### 4.2 分类判定

| 类别 | 判定 | 档案目录 |
|------|------|---------|
| 姻亲 | 能在某个家族族谱中找到关系节点 | `characters/姻亲/` |
| 社会关系 | 不在任何家族谱内，但重要且与多家族叙事相关 | `characters/社会关系/` |

### 4.3 社会关系角色档案必含字段

参照 `characters/社会关系/模板.md`，核心字段：

- 身份定位（一句话）
- **与各家族的关系表**（米家/李家/杨家/何家/于家各自的关系与关键事件）
- 人物背景、性格、说话风格
- 关键场景（含叙事意义）
- **在小说中的功能**（叙事/多家族联动/主题/情感）
- 与主线的关系弧线（按年代）

## 五、写作规范

### 5.1 镜头切换写作要点

1. **时间必须对齐**：同一章内所有镜头时间跨度一致，切换时标注时间（`1916-03-15 09:15`），严禁时间倒流
2. **切换要留衔接**：每个镜头结尾留"切点"（悬念/因果/呼应），保证镜头间逻辑连贯
3. **每镜头一个焦点**：单镜头内只推进一个家族（或一个社会关系角色）的核心事件
4. **家族线均衡**：避免连续 3 章只推一条线；未登场家族在时间轴对齐表中标注
5. **社会关系线节奏**：社会关系角色按需出场，不是每章都在

### 5.2 与既有写作规范的关系

镜头切换模式是既有 `novel-outline` 多线结构 + `novel-writing` 多线切换技巧的**升级具体化**：

| 既有规范 | 镜头切换模式 |
|---------|-------------|
| 多线结构（A线/B线） | 家族线（每家族一线）+ 社会关系线 |
| 时间同步切换 | 必须有时间轴对齐表支撑 |
| 因果切换 / 悬念切换 | 家族间因果、悬念切换（跨家族联动） |
| 交织规则 | 镜头切换节奏（单章 2-4 镜头） |

## 六、实施清单（接入工作流）

- [ ] 卷首建立**时间轴对齐表**（各家族 + 社会关系线）
- [ ] 大纲按"镜头序列 + 时间对齐"结构编写
- [ ] 细纲场景列表标注**镜头归属**（家族线/社会关系线）
- [ ] 正文 HTML 注释增加 `line=` 字段（镜头归属）
- [ ] 角色档案按**姻亲/社会关系**分类存放
- [ ] 社会关系角色按模板建档，素材由创作者提供
- [ ] 新增社会关系角色时**联动修改已有草稿**并留痕（`.novel/tracking/修改记录.md`）
