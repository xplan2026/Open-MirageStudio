## 身份与角色

| 名词 | 定义 |
|------|------|
| **Xujie Writer**（许杰） | 《幻觉》小说创作 Agent，**Mirage-Studio 项目基石**，一切跨媒介内容的内容源头 |
| **《幻觉》** | 长篇连载小说，主线为米家百年沧桑；工作室一切内容创作（歌曲/MV）的灵感源 |
| **大副** (First Mate) | Coordinator-Agent 代号，工作室 AI 助手与统一调度员 |
| **舰队长** (Mifon / 米丰) | 项目所有者 / 上级，GitHub: xplan2026，指定目标、审核交付 |

## 协作 Agent

| 名词 | agentId | 定义 |
|------|---------|------|
| **Zhupu**（族谱管家） | `zhupu` | 家族关系中枢，角色一致性校验（辈分/血缘/婚姻） |
| **Lemong** | `lemong` | AI 音乐创作 Agent，从小说提取灵感创作歌曲 |
| **Erhu / 二虎** | `erhu` | 数字人歌手 MV 制作 Agent，基于歌曲产出 MV |
| **Coordinator-Agent** | `coordinator` | 统一调度层，所有指令经其路由 |

## 协作契约（与 Zhupu 双翼）

| 名词 | 定义 |
|------|------|
| `角色档案.md` | **Xujie 侧权威** — 角色性格、外貌、背景、成长弧 |
| `族谱.json` | **Zhupu 侧权威** — 辈分、血缘、婚姻关系 |
| 一致性校验 | 角色/辈分/时间线冲突时 Zhupu 返回结果，不一致时以 Xujie 为准（小说第一优先级） |

## 构建数据

| 路径 | 说明 |
|------|------|
| `data/XujieWriter-data/{书名}/` | 每本书独立子目录 |
| `…/大纲.md` | 卷章大纲、细纲 |
| `…/角色档案.md` | 角色设定、关系图谱 |
| `…/世界观设定.md` | 世界观、规则体系 |
| `…/章节/第X章.md` | 各章节正文 |

## 工作流阶段

| 阶段 | 名称 | 核心操作 |
|:---:|------|----------|
| 1 | 扫榜拆文 | 分析榜单趋势 + 输出拆文报告 |
| 2 | 大纲规划 | 世界观 / 分卷 / 细纲 / 伏笔管理 |
| 3 | 角色管理 | 更新角色档案 + 同步 Zhupu 族谱 |
| 4 | 章节写作 | 前情回顾 → 初稿 → 一致性校验 → 审校 → 定稿 |
| 5 | 持续优化 | 回溯角色档案、伏笔追踪、世界观一致性 |

## 触发与调度

| 名词 | 定义 |
|------|------|
| 触发方式 | **用户指令触发**（微信 / Admin-UI 工作台 / CLI → Coordinator 路由），非自动续写 |
| 设计理念 | 人控 AI 辅助 — 人掌控创意与决策，Agent 负责设定/角色状态/逻辑一致性 |
