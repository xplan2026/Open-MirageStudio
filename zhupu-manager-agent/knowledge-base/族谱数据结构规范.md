# 族谱数据结构规范

本文档定义 `Zhupu-manager-agent` 的数据存储格式，是所有脚本操作的单一数据源。

## 文件存储结构

```
data/Zhupu-data/
├── INDEX.md                  # 全局索引
└── {家族名}/
    ├── 族谱.json              # 族谱主数据
    ├── 家训.md                # 家训文本（可选）
    └── export/               # 导出文件
        └── {家族名}-{格式}.{拡张子}
```

## 族谱.json 格式

### 顶层结构

```json
{
  "family_name": "字符串 — 家族名称",
  "created_at": "ISO 8601 创建时间",
  "updated_at": "ISO 8601 最后更新时间",
  "description": "字符串 — 家族简介",
  "culture": {
    "motto": "字符串 — 家训（可选）",
    "emblem": "字符串 — 族徽/图腾（可选，本地路径或 URL）",
    "origin": "字符串 — 家族渊源（可选）",
    "notes": "字符串 — 备注"
  },
  "generation_names": {
    "1": "始祖",
    "2": "二世",
    "3": "三世"
  },
  "members": {
    "<member_id>": { "成员对象" }
  }
}
```

### 成员对象

```json
{
  "id": "member_001",
  "name": "张三",
  "style_name": "子明",
  "generation": 2,
  "gender": "男",
  "avatar": "",
  "birth": "1910-03-15",
  "death": "1995-12-20",
  "father": "member_001",
  "mother": "member_002",
  "spouse": ["member_003"],
  "children": ["member_004", "member_005"],
  "achievements": [
    { "type": "科举", "title": "进士", "year": "1547", "detail": "嘉靖二十六年进士" }
  ],
  "notes": "曾任私塾先生"
}
```

### 字段说明

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| id | 自动生成 | string | 唯一标识，格式 `member_001`，从 1 递增 |
| name | ✅ | string | 姓名 |
| style_name | - | string | 表字/笔名/别号。古代用作表字，现代可用作笔名或族谱排序名备用 |
| generation | ✅ | number | 辈分，从 1 开始 |
| gender | - | string | `男` 或 `女`，默认 `男` |
| avatar | - | string | 头像路径（本地文件路径或 URL），可选 |
| birth | - | string | 出生年月，格式 `YYYY` 或 `YYYY-MM-DD` |
| death | - | string | 去世年月 |
| father | - | string | 父亲 member_id |
| mother | - | string | 母亲 member_id |
| spouse | - | array | 配偶 member_id 数组 |
| children | - | array | 子女 member_id 数组 |
| achievements | - | array | 成就/荣誉列表，每项含 `type`(分类), `title`(名称), `year`(年份), `detail`(详情) |
| notes | - | string | 个人备注 |

### achievements 成就对象

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| type | ✅ | string | 成就分类标签，如 `科举`/`官职`/`军功`/`荣誉`/`著作`/`贡献` 等 |
| title | ✅ | string | 成就名称，如 `进士`/`将军`/`谥号文忠` |
| year | - | string | 年份或时间段 |
| detail | - | string | 详细描述 |

### id 生成规则

- 格式: `member_` + 递增数字，补齐 3 位
- 初始: `member_001`, `member_002`, ...
- 删除 ID 不重用

## 关系约束

1. **父子关系一致性**: 若 A 是 B 的父/母，则 B 必须在 A 的 `children` 数组中
2. **辈分连续性**: 子女的 generation = 父/母的 generation + 1
3. **无循环**: 禁止 A 是 B 的祖先同时也是 B 的子孙
4. **配偶对称**: 若 A 的 `spouse` 包含 B，则 B 的 `spouse` 也应包含 A
