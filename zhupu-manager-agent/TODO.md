### 详细说明

**1️⃣ 成就荣誉检索**
- `achievements` 字段已完成数据结构定义和录入支持
- 查询支持 `--achievement-type <分类>` 按类型筛选
- 查询支持 `--has-achievement` 列出所有有成就的成员
- 所有脚本（query/tree/export）均已显示成就信息

**2️⃣ 高级关系查询**
- 根据已有父子/夫妻关系，推导出隔代亲属关系
- 支持：爷爷、奶奶、外公、外婆、孙子、孙女、舅舅、姑父、堂兄弟、表姐妹等
- 需考虑父系和母系两条线索

**3️⃣ 族谱导入**
- CSV 格式：每行一个成员，指定 parent_id 建立关系
- Excel 格式：同上（需引入 xlsx 解析库）
- 家谱文本格式：从自然语言描述中解析（较复杂，可延后）

**4️⃣ 关系图谱 SVG/HTML 生成**
- 非交互式 Web 界面，而是导出为独立的 .svg 或 .html 文件
- 用 D3.js 或类似工具在 Node.js 端生成
- 输出到 `export/` 目录

**5️⃣ 纪念日提醒**
- 基于 `death` 字段，提前 N 天提醒
- 输出格式：控制台提示 + 可选写入日志文件

**6️⃣ 生日提醒**
- 基于 `birth` 字段，提前 N 天提醒
- 与 [4] 共用提醒机制（可复用提醒模块）

**7️⃣ 数据备份**
- 备份 `data/Zhupu-data/` 到 `data/Zhupu-backup/` 目录
- 每次备份带时间戳
- 自动清理 30 天前的旧备份

**8️⃣ Web 界面可视化 🔥（重要）**
- 基于 Web 的族谱查看与编辑界面
- 可查看关系图谱（交互式）
- 可在线添加/编辑成员
- 须前 6 项完成后才启动
