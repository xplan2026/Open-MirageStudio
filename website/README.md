# 幻觉 IP 官方网站

本网站是「幻觉」独立自媒体 IP 的官方前端门户，聚合展示小说、音乐、MV、族谱四大内容板块及社区互动功能。

## 网站定位

「幻觉」是一个以长篇连载小说为骨架、AI 原生音乐/MV 为血肉、家族族谱为经脉的跨媒介内容 IP。本网站作为所有内容的统一展示入口：

- **小说** — 连载《幻觉》各卷章节，读者可逐章阅读
- **音乐** — 乐盟 Agent (lemong-agent) 创作的所有原创歌曲
- **MV** — 二虎 (Erhu) 数字人歌手演绎的音乐 MV 作品
- **族谱** — 《幻觉》小说中所有角色家族的族谱可视化
- **社区** — 读者互动、评论、讨论区

## 技术栈

| 层级 | 选型 | 说明 |
|------|------|------|
| 框架 | **Astro** | 纯静态 SSG，零运行时，Islands 架构 |
| CSS | **Tailwind CSS** | 高效开发，内容站点友好 |
| 族谱可视化 | **D3.js** | SVG 交互式族谱树 |
| 部署 | 阿里云 ECS | 复用原服务器 |
| 域名 | [已配置域名] | 已有域名 + SSL |
| Web 服务器 | Nginx | 直接 serve 静态文件 |
| 数据源 | `data/` 目录 | 构建时读取，生成静态页面 |
| 分发链路 | GitHub 中转 | WebIDE → git push → server git pull → build |

### 为什么是 Astro

服务器仅 1.8G 内存，不能跑 Node 进程常驻。Astro 构建产出纯 HTML/CSS/JS 静态文件，Nginx 直接 serve，内存占用接近于零。小说章节、歌词、MV 列表等 90% 的内容是纯展示，不需要运行时框架。只有族谱树和播放器需要 JS 交互，用 Astro Islands 按需加载即可。

```
│   │   │   ├── index.tsx      # 家族列表页

├── package.json
└── deploy/              # 部署配置
    └── nginx.conf       # Nginx 配置
```

## 页面设计

### 小说板块

| 页面 | 路由 | 内容 |
|------|------|------|
| 小说首页 | `/novel` | 卷章目录树、简介、阅读进度 |
| 章节详情 | `/novel/:chapter` | 章节正文、导航（上一章/下一章）、评论 |

### 音乐板块

| 页面 | 路由 | 内容 |
|------|------|------|
| 音乐首页 | `/music` | 歌曲列表（支持按风格筛选）、播放器 |
| 歌曲详情 | `/music/:song` | 歌曲播放、歌词展示、创作背景、关联 MV |

### MV 板块

| 页面 | 路由 | 内容 |
|------|------|------|
| MV 首页 | `/mv` | MV 作品列表、视频缩略图墙 |
| MV 详情 | `/mv/:mv` | 视频播放器、作品信息、歌词字幕 |

### 族谱板块

| 页面 | 路由 | 内容 |
|------|------|------|
| 族谱首页 | `/family` | 家族列表、简介 |
| 族谱详情 | `/family/:family` | 交互式族谱树、成员详情卡片 |

### 社区板块

| 页面 | 路由 | 内容 |
|------|------|------|
| 社区首页 | `/community` | 读者评论墙、讨论话题、最新动态 |

## 设计语言

- **主色调**: 待定（建议暗色系，呼应"幻觉"主题）
- **风格**: 文学感 + 现代极简
- **字体**: 中文衬线体（正文）+ 无衬线体（UI）
- **动效**: 页面切换过渡动画、族谱树展开动画、音乐播放器可视化
