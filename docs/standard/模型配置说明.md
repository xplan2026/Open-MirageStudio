# 模型配置说明

> **状态**: 已确认  
> **最后更新**: 2026-07-14

---

## 固定使用的模型供应商

本项目固定使用以下两个模型供应商：

| 供应商 | 余额状态 | API 地址 |
|--------|----------|----------|
| **DeepSeek** | ✅ 有余额，正常使用 | `https://api.deepseek.com/v1` |
| **智谱 (Zhipu)** | ❌ **无余额，未充值** | `https://open.bigmodel.cn/api/paas/v4` |

---

## DeepSeek — 可用模型

| 模型 ID | 名称 | 类型 | Context | Max Tokens |
|---------|------|------|---------|------------|
| `deepseek-chat` | DeepSeek-V4-Pro | 文本 | 131K | 65K |

> DeepSeek 有余额，无使用限制。作为首选供应商。

---

## 智谱 (Zhipu) — 可用模型（全部免费）

| 模型 ID | 类型 | 用途 |
|---------|------|------|
| `GLM-4.7-Flash` | 文本 | 通用对话、文本生成 |
| `GLM-Z1-Flash` | 推理 | 需要推理能力的任务 |
| `GLM-4V-Flash` | 多模态 | 支持文本+图片输入 |

### ⚠️ 硬性约束

> **🔴 智谱 API 账号未充值，没有余额！**
>
> 调用智谱 API 时（推理/文本/长文本/文生图/多模态等任何任务），**必须**从以上三个免费 Flash 模型中选择。
>
> **严禁使用任何收费模型**，包括但不限于：`glm-5`、`glm-5.1`、`GLM-4-Plus` 等。
> 收费模型会返回 `401 令牌已过期或验证不正确`，导致任务中断。

---

## 模型选择策略

1. **首选 DeepSeek** — 有余额，稳定可靠，作为默认选择
2. **智谱仅用于特有场景** — 需要智谱特有能力的任务（如 GLM 推理、多模态等），使用对应的免费 Flash 模型
3. **未知场景默认走 DeepSeek**

---

## 配置位置

各 Agent 的模型配置在各自的环境变量/配置文件中定义。
