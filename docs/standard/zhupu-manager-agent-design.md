# Zhupu Manager Agent — 族谱管理设计文档

> **创建日期**: 2026-08-21
> **版本**: v1.0
> **状态**: 已部署
> **定位**: 数字化家族成员管理、族谱树构建、家族关系查询与可视化
> **数据来源**: GitHub 仓库 `https://github.com/xuan2026/zhupu.git`
> **CI/CD**: GitHub Actions + Cloudflare Pages 部署

---

## 一、定位与职责

### 1.1 核心定位

Zhupu Manager Agent 是 Mirage-Studio 的**族谱管理专用 Agent**，配合 Xujie Writer Agent 的小说《幻觉》角色管理，确保角色设定的一致性。

族谱是《幻觉》的基础数据，《幻觉》是自媒体（歌曲/MV）的创作源。小说主线为**米家百年沧桑**。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| **族谱管理** | 数字化家族成员管理、族谱树构建 |
| **关系查询** | 家族关系查询与可视化 |
| **族谱联动** | 接收 Xujie Writer Agent 的角色更新请求，自动同步族谱 |
| **长期记忆** | 维护跨家族联姻图（根状结构），优化 LLM 缓存命中 |
| **数据可视化** | ASCII 根状图 + Mermaid 图，支持人类可读与机器可读 |

### 1.3 与其他 Agent 的关系

```
Xujie Writer Agent (小说创作)
    ↓ (生成新章节)
    ├─► 提取新角色 → 调用 Zhupu Manager Agent
    ├─► 更新族谱（米家/姻亲/社会关系）
    └─► 同步跨家族联姻图
```

## 三、族谱数据结构

### 3.1 核心数据：族谱.json

每个家族有一个独立的 `族谱.json` 文件，包含完整的家族成员信息：

```json
{
  "familyName": "米家",
  "origin": "四川潼南",
  "generations": 4,
  "members": [
    {
      "id": "G1-MFY",
      "name": "米福云",
      "gender": "男",
      "birthYear": 1914,
      "deathYear": 2009,
      "generation": 1,
      "isMainLine": true,
      "spouse": [
        {
          "name": "徐氏",
          "status": "separated"
        },
        {
          "name": "李维贞",
          "marriageYear": 1950,
          "family": "李家"
        }
      ],
      "children": ["G2-MNS", "G2-MNH", "G2-MNH-2", "G2-MNF", "G2-MNZ"],
      "description": "潼南米氏→父亡避债逃江城→续弦李维贞→95岁卒"
    }
  ]
}
```

### 3.2 字段定义

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | ✓ | 唯一标识符（如 `G1-MFY`） |
| `name` | string | ✓ | 姓名 |
| `gender` | string | ✓ | 性别（"男"/"女"） |
| `birthYear` | number | ✓ | 出生年份 |
| `deathYear` | number | ✗ | 死亡年份（未填则健在） |
| `generation` | number | ✓ | 世代（1~4） |
| `isMainLine` | boolean | ✗ | 是否主系长房 |
| `spouse` | array | ✗ | 配偶信息（姓名、状态、家族） |
| `children` | array | ✗ | 子女 ID 列表 |
| `description` | string | ✗ | 人物简介 |

### 3.3 家族清单

| 家族 | 人数 | 代数 | 简介 |
|------|------|------|------|
| 米家 | 27人 | 4代 | 四川潼南米氏，小说《幻觉》核心家族。潼南望族药铺起家→米湘一代没落→米福云避债入江城。 |
| 何家 | 23人 | 3代 | 江城何氏，米丰配偶何妮的原生家族。教育世家，何开华为数学教师，于先淑为语文教师。 |
| 于家 | 38人 | 4代 | 四川大竹于氏，地主兼酒坊起步。于先淑、于先贞姐妹为家族核心传承线，关联何家与宋家。 |
| 李家 | 23人 | 4代 | 米丰外婆/奶奶的母族。李刘氏为家族起点，二代六子女多受高等教育，从大校到工程师。 |
| 杨家 | 23人 | 4代 | 米丰母亲的家族。三代人才辈出：医药精英杨柯、桥梁工程师张浪、律师张燕。 |

### 4.2 主根：米家直系长房

| 世代 | 成员 | 生卒 | 角色 | 概要 |
|:---:|------|------|------|------|
| 一世 | **米福云** | 1914-2009 | 根基 | 潼南米氏→父亡避债逃江城→续弦李维贞→95岁卒 |
| 二世 | **米南生** | 1943- | 传承 | 原配徐氏之子·直系唯一长房。1岁寄养→6岁入江城→八年军旅→英语教师→储运处长 |
| 三世 | **米丰** | 1973- | 叙述者 ★ | 《幻觉》作者/主角。修车→海军→练歌房→国企→青岛→网约车/编程/自媒体 |
| 四世 | **米欢 / 米杰** | 2001- / 2008- | 根尖 | 米丰与何妮之子女，代际知识传递的观察对象 |

### 4.3 侧根设计

#### 侧根 LR01：李家 — 附着于 G1 米福云（续弦 1950）

> 最早侧根——与主根共生最久，通过李维贞直接接入米家一世

| 层级 | 方向 | 内容 |
|:---:|------|------|
| ↑ 上溯 | 李刘氏(一世) | 江北县人，夫亡逃难至江城纸厂。育李一至李六共6子女。1979年卒 |
| — 附着点 | **李维贞(李三)** | 李家二世·嫁米福云为续弦(1950年，18岁)。12岁进厂。育三女二子 |
| — 同源 | **李二** | 李刘氏次女，嫁杨一(杨家一世)——参见 LR02 |
| ↓ 根须 | 李一→李七→李十一 | 大舅公一脉 |

#### 侧根 LR02：杨家 — 附着于 G2 米南生（婚姻）

> G2层侧根——米家二代婚姻，引入杨家基因，同时上溯至李家(李二)

| 层级 | 方向 | 内容 |
|:---:|------|------|
| ↑ 上溯 | 杨一(一世·1916-1988) | 江北农场场长，擅竹编。妻**李二**(李刘氏次女，与 LR01 同源) |
| — 附着点 | **杨常玉(杨三)** | 杨家二世·米南生之妻，米丰之母。务农卖菜→转大集体。2022年摔伤去世 |
| — 同期 | 杨二~杨七(6兄弟姐妹) | 各有发展：华西医生/务农/工人/经商/工人 |

#### 侧根 LR03：何家 — 附着于 G3 米丰（婚姻 1999）

> G3层侧根——主角配偶家族，通过何妮直接关联小说核心叙事

| 层级 | 方向 | 内容 |
|:---:|------|------|
| ↑ 上溯 | 何开华(一世·1930-2002) | 江津人·数学教师。兄弟四人(开华/开敏/开智/开健)。妻于先淑(LR04) |
| — 附着点 | **何妮** | 何家二世·1970年生，米丰之妻。自考本科→练歌房→水晶工作室 |
| — 同期 | 何林(1950-2019) | 于先淑前夫之子入何家。与米丰交好：守夜/青岛开餐馆。肝癌去世 |

#### 侧根 LR04：于家 — 附着于何家（间接关联 G3 米丰）

> 二级侧根——于先淑通过嫁何开华间接进入米家网络，与米家隔一层

| 层级 | 方向 | 内容 |
|:---:|------|------|
| ↑ 上溯 | 于老爷(一世·-1950) | 大竹地主兼酒坊，三老婆十子女。解放后被枪毙 |
| — 附着点 | **于先淑** | 于家二世长女。一婚嫁李家(夫被枪毙)→逃难江城挑沙→二婚何开华→语文教师 |

### 4.4 横向闭合回路

侧根间存在两条闭合回路，使根系网络更加稳固：

| 回路 | 路径 | 含义 |
|------|------|------|
| CC01 | 李刘氏 → 李二(嫁杨一) → 杨常玉 → 米南生 ← 米福云 ← 李维贞(李三) | 米家G1续弦李家，米家G2又通过杨家间接娶李二之女——**两代人双线汇入主根** |
| CC02 | 于先淑一婚(李家) → 二婚(何家) → 何妮嫁米丰 | 于家通过何家关联米家；于先淑前夫为李家，**自成微小闭合** |

### 4.5 世代对照表

| 米家世代 | 李家 | 杨家 | 何家 | 于家 |
|:---:|------|------|------|------|
| 1世(米福云) | **2世(李维贞·附着)** | — | — | — |
| 2世(米南生) | 2世(继母)+3世 | **2世(杨常玉·附着)** | 1世(何开华) | 2世(于先淑) |
| 3世(米丰) | 4世(根须) | 3世(根须) | **2世(何妮·附着)** | 3世(宋黔等) |
| 4世(米欢/米杰) | 5世(远根须) | 4世(远根须) | 3世(根须) | 4世(根须) |

### 4.6 根须化规律

侧根随着世代增加，由近及远、由密到疏，自然演化为根须：

| 距主根距离 | 代表 | 关系密度 |
|-----------|------|---------|
| 0层(主根本身) | 米南生↔米丰 | 直接父子，小说的核心叙事 |
| 1层(直接附着) | 杨常玉(母)、何妮(妻) | 小说主要人物的直系亲属 |
| 2层(侧根一代亲属) | 杨二~杨七、何华/何珍/何林 | 主角姨舅姑姨，有互动但非核心 |
| 3层(根须·表亲) | 杨柯/张浪/杨洋/张燕、刘颖 | 偶尔提及，推动支线情节 |
| 4层+(远根须) | 官二/官三、九舅之子、满姨之子 | 几乎不出现，仅作背景存在 |

## 五、技术实现

### 5.1 CLI 入口

```bash
# 查询家族成员
zhupu-manager-agent query --family "米家" --name "米丰"

# 更新族谱（来自 Xujie Writer）
zhupu-manager-agent update --family "米家" --type "marriage" --data " spouse.json"

# 生成关系图
zhupu-manager-agent visualize --output-format "mermaid"

# 导出 Markdown
zhupu-manager-agent export --family "米家" --format "markdown"
```

### 5.2 与 Xujie Writer Agent 的联动

当小说章节完成时，Xujie Writer Agent 自动解析新角色：

```javascript
// 伪代码
const newCharacters = extractCharacters(chapter);

// 分类判定
const categorized = newCharacters.map(char => {
  const familyTree = findInFamilyTrees(char.name);
  if (familyTree) {
    return { ...char, type: '姻亲', family: familyTree.familyName };
  } else {
    return { ...char, type: '社会关系' };
  }
});

// 更新族谱
for (const char of categorized) {
  if (char.type === '姻亲') {
    await zhupu.updateFamily(char.family, char);
  }
}

// 同步跨家族联姻图
await zhupu.syncGraph();
```

### 5.3 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `ZHUPU_DATA_DIR` | 数据目录路径 | `data/Zhupu-data` |
| `ZHUPU_EXPORT_DIR` | 导出目录 | `data/Zhupu-data/{家族名}/export` |

## 六、长期记忆设计

### 6.1 设计原则

| 原则 | 说明 |
|------|------|
| **根状结构** | 米家直系长房为主根（纵轴），其他家族为侧根（横向分支），随世代增加向根须发展 |
| **确定性内容** | 固定排序、无时间戳、无随机 ID → 最大化 LLM 缓存命中 |
| **扁平自包含** | 单文件索引，回答跨家族关系无需遍历 5 个 JSON |
| **单一信任源** | 数据从各家族 `族谱.json` 提取，此处为关系索引 |

### 6.2 长期记忆文件

| 文件 | 格式 | 用途 |
|------|------|------|
| `graph/跨家族联姻图.json` | JSON | 机器可读的根状关系图（主根·米家直系长房 + 4侧根 + 根须层 + 世代深度表） |
| `graph/跨家族联姻图.md` | Markdown | 人类可读 + ASCII根状总览 + Mermaid 图 + 根须化规律（Agent 长期记忆文件） |

### 6.3 维护说明

当任一 `族谱.json` 新增跨家族婚姻成员时，务必同步更新 `graph/跨家族联姻图.json` 和 `graph/跨家族联姻图.md`：

1. 主根世代表（如米家有新世代）
2. 对应侧根的上溯/附着/根须层
3. 世代对照表 + Mermaid 图
