## 概述

**"微缩人类冒险"**（Miniature Tiny-Person FX）：把真人缩小到手掌大小，放进真实生活场景中，让手机、桌子、玩具等普通物品变成巨大的冒险世界。作者使用 **Seedance 2.0** 生成。

## 提示词模板（完整版）

### 风格

```
微缩小人特效片（Miniature Tiny-Person FX），真实摄影（Photorealistic），
电影级微距摄影（Macro Cinematic Photography），真实桌面环境融合奇幻冒险，
浅景深（Macro Depth of Field），8K超清，竖屏9:16，抖音爆款短视频质感。
```

### 主题

```
《桌面上的微型冒险》—— 一个巴掌大小的迷你人，
在真实AI工作者的桌面世界展开一场惊险刺激的闯关之旅。
所有物体保持真实比例，迷你人与桌面物品约1:15比例。
```

### 场景

```
完全还原参考图片中的真实桌面：
- 木质电脑桌
- 左侧墙面照片、贴纸、手稿
- 中间显示器播放足球画面
- 桌面上的笔记本电脑
- 右侧竖屏显示器
- 白绿色机械键盘
- 黑色鼠标
- 蓝色桌垫
- 多部手机
- 白色耳机盒
- 充电线缆组成的"电线森林"
- 黑色手机支架
- JBL音箱盒
- 绿色、白色药瓶
- 黄色饮料罐
- 文件纸张和各种办公杂物
```

### 角色

```
主角：一个巴掌大的迷你年轻人，穿米色连帽卫衣、黑色裤子、运动鞋。
动作像电影探险家一样奔跑、攀爬、跳跃，保持角色连续一致。
```

### 负面提示词

```
不要改变桌面布局；不要生成浴室；不要出现花洒、浴缸、鳄鱼玩具；
不要增加不存在的家具；不要改变电脑、键盘、显示器位置；
不要卡通化；不要低清；不要人物比例错误；不要多人；不要改变原照片真实环境。
```

## 操作步骤

1. **拍摄场景照片** — 拍一张自己生活中的真实场景照片
2. **让AI融合元素** — 把照片和提示词一起提交给AI，AI会自动把提示词里的元素（如鼠标、键盘）替换成照片里的对应物品，使生成内容与图片更好融合
3. **生成微缩小人形象** — 用自己的照片生成一个微缩版小人角色
4. **统一角色形象** — 让AI结合微缩版角色图片重新生成形象描述，或手动修改，确保视频中角色穿搭一致
5. **生成视频** — 把准备好的提示词和参考图，在对应位置插入参考图，提交给视频生成工具
6. **推荐工具** — Seedance 2.0
