# 视频作品·创作质量标准与规范

## 1. 基础质量标准

| 判断维度 | 优质 | 普通 | 低质 |
|---------|------|------|------|
| **1. 封面** | - 封面清晰、美观，精准传达视频核心亮点或主旨，无文字遮挡或模糊信息，与内容高度匹配<br>- 高度概括内容核心，无夸大，用户预期与实际观看体验一致 | - 清晰度一般，与内容基本相符，但缺乏吸引力或略显杂乱<br>- 略有美化或未体现最佳信息点<br>- 封面为分镜头图/组图，有文字有标题 | - 模糊、变形，与内容无关，显水印、低俗/不适内容<br>- 封面与内容完全不符，属于“封面误导性极强”<br>- 仅纯黑色背景+文字（含艺术字）<br>- 封面为分镜头图/组图，无文字无标题 |
| **2. 标题** | - 精准概括视频核心价值，语言精炼、无错别字，符合逻辑专业属性，无夸张误导 | - 基本说明内容，但略显平淡、冗长或存在轻微语病 | - 与内容严重不符，存在夸大或夸张，无信息量 |
| **3. 时长**<br>（客观物理时长） | - 时长：**16s ~ 5min** | - 情况1：时长 **< 15s**<br>- 情况2：时长 **> 5min** | - 情况1：时长 **≤ 10s**<br>- 情况2：时长 **> 5min**（与普通重复，原文如此） |
| **4. 字幕** | - 完整、准确，时间轴精确，字体清晰可读，位置合理，不影响画面主体<br>- 与画面有一定匹配度，有一定美感 | - 存在少量错别字或时间轴轻微偏差，但整体可理解 | - 严重错误、错位、无法辨认 |
| **5. 音频质量** | - BGM贴合视频情绪与节奏，音量与旁白/音效平衡<br>- 人声/旁白清晰无杂音，无爆音、削波；环境音效与BGM层次分明 | - 有BGM/旁白，但音量略不均衡或风格匹配度一般，或音画不同步 ≤3s，不影响整体观感<br>- 轻微低频或音量不均，但不影响信息获取 | - 无BGM（在需要氛围的场景下）<br>- BGM音量严重失衡，与内容冲突明显<br>- 人声模糊、爆音严重、音量过小，音频断断续续或音画不同步 >3s |
| **6. 画质与分辨率** | - 分辨率 ≥ 1080p，画面清晰锐利，无明显压缩、噪点或模糊区域 | - 分辨率 720p 左右，画面整体可接受，但细节模糊或存在轻微压缩痕迹 | - 分辨率低于720p，画面严重模糊，有明显压缩痕迹 |
| **7. 生成质量与一致性** | - 无明显AI生成瑕疵，人物肢体、光影、文字、物体运动均符合物理逻辑，画面连贯自然<br>- 整段视频主体形象连贯一致 | - 存在轻微AI痕迹/瑕疵（如局部闪烁、手指轻微扭曲），但不影响整体理解和专业感<br>- 主体不一致 <3s，不影响整体 | - 明显AI瑕疵（面部模糊、文字模糊及出现/消失、画面撕裂）影响观感<br>- 视频出现 >3s主体不一致，前后画面明显不统一<br>- 「情节需要」定义为情节设计类似“突破次元壁”等转变画面 |

## 2. 垂类质量标准

### 2.1 电商广告

#### 2.1.1 产品展示、功能卖点、营销促销、信息流/引流广告

- **垂类特征**：以直接推动产品销售或获取用户转化为核心目的，内容围绕产品本身、卖点或促销信息展开，强调即时效果。
  - **产品展示**：通过真实或模拟场景，直观呈现商品外观、形态、使用方式或核心特征。
  - **功能卖点**：聚焦技术、材质或结构优势，通过具象或抽象视觉化，解析并解决用户痛点。
  - **营销促销**：以推动即时转化为核心，明确传递时间、价格、优惠力度、品类范围等。
  - **信息流/引流广告**：适配平台分发，强调原生感与强吸引力开场，兼顾兴趣激发与转化。

| 维度 | 优质 | 普通 | 低质 |
|------|------|------|------|
| **稳定性一致性** | - 产品形态前后一致，光影符合物理逻辑<br>- 视频内容无抽帧 | - 产品有微小变形（如边缘波浪）或轻微色差，但不影响认知，光影符合逻辑<br>- 无抽帧 | - 产品明显变形或前后不一致，光影模糊，明显色差<br>- 视频存在抽帧 |
| **呈现质量** | - 在视频前1/3时间内展示产品/卖点/促销信息，同时：<br>  - 卖点准确：特效直接、唯一对应卖点（如“热力”用红外光晕+空气扭曲）<br>  - 展示效果清晰：卖点动作在3秒内被理解，无多余遮挡 | - 在视频前2/3时间内展示，同时：<br>  - 卖点基本准确：特效相关但存在多余或混淆元素（如防水同时出现水花和火焰）<br>  - 展示清晰度不高：5秒内可识别，但部分特效杂乱或轻微遮挡 | - 在视频前2/3时间内展示，同时：<br>  - 错误或无关：特效与卖点无关、重复或模糊<br>  - 模糊或重复：超过5秒仍无法理解 |

---

#### 2.1.2 Mockup、企宣/品宣

- **垂类特征**：侧重于品牌形象展示、设计预览或企业实力呈现，非直接推销具体产品或促销活动。
  - **Mockup**：以模板化、框架式视觉形式呈现内容布局、信息结构或产品状态，强调形式清晰、信息层级明确，常用于提案或预览。识别要点：画面多为未填充真实内容的版式、线框、占位图，无真实使用场景。
  - **企宣/品宣**：以塑造企业形象、传递品牌理念或展现综合实力为核心，涵盖发展历程、社会责任、技术实力、团队文化等。识别要点：常见企业Logo、品牌slogan、办公环境、工厂生产线、资质荣誉等，弱化产品功能卖点。

| 维度 | 优质 | 普通 | 低质 |
|------|------|------|------|
| **主旨清晰度** | - 视频在1/3时长内清晰传递品牌调性或产品场景<br>- 完整呈现品牌Logo、Slogan、核心价值主张（如“创新”“可靠”） | - 视频过半才明确宣传内容，情绪传递较弱<br>- 有Logo和Slogan但价值主张不明确 | - 视频过半仍不清楚在宣传什么<br>- 缺少Logo或Slogan，或展示内容与品牌无关 |
| **稳定性和一致性** | - 企宣/品宣：无崩坏/瑕疵、AI增殖物，Logo/展示文字清晰无乱码<br>- mockup：界面展示完整，动画效果流畅，无瑕疵 | - 企宣/品宣：轻微错误（如背景微小扭曲），但不影响品牌识别<br>- mockup：界面展示基本完整，但有轻微变形或界面瑕疵 | - 企宣/品宣：Logo文字乱码、颜色错误、产品明显变形或前后不一致<br>- mockup：UI界面展示不完整，文字乱码，光影错误 |
| **呈现质量**<br>（主要面向mockup） | 命中 ≥2个：<br>- 叙事清晰度：动画具有完整功能与场景说明（如完整用户任务：登录→浏览→支付→完成），关键步骤有明确起点和逻辑过渡<br>- 交互逻辑合理性：反映真实交互行为（按钮按压/返回/取消，滑动删除有弹性或轨迹）<br>- 视觉焦点与引导：主动引导注意力至重要操作（通过微光效、放大、色彩渐变、动态方向）<br>- 配乐有层次（起承转合），配音专业无杂音 | 命中 ≥1个：<br>- 叙事清晰度：至少完整呈现一个典型用户任务（登录→浏览→选择→支付→完成）<br>- 交互逻辑合理性：基本反映真实交互<br>- 视觉焦点与引导：有引导效果<br>- 配乐有层次，配音专业 | 命中 ≥1个：<br>- 叙事清晰度：动画不具有完整功能与场景说明，仅菜单、按钮、图标形式，看不出用户要解决的问题，或流程过于复杂（如网络加载、错误提示），显得不真实<br>- 交互逻辑不合理：操作流程不符合逻辑<br>- 视觉焦点与引导：无视觉引导效果<br>- 配乐与画面脱节，配音有回声或卡顿 |

#### 2.1.3 创意TVC、公益广告

- **垂类特征**：以情感共鸣、价值观传递或社会倡导为主线，非直接商业转化，弱化产品功能宣讲。
  - **创意TVC**：表达品牌或产品精神内核、价值观或情感主张，追求情绪共鸣与审美表达。识别要点：艺术水准较高，常有故事性、意象化，品牌Logo出现但非核心推销点。
  - **公益广告**：以社会公共利益为主题，倡导公众关注特定议题（如环保、健康、教育、安全）或改变行为，非商业目的。识别要点：无商业品牌推广，常带公益组织标识、倡议口号或行动呼吁。

| 维度 | 优质 | 普通 | 低质 |
|------|------|------|------|
| **创意价值** | - 主题新颖或对社会/人性有洞察<br>- 主题/表达手法/画风非常规或非常见，且执行到位（如非线性叙事） | - 主题常见，表达清晰但无新意/惊喜<br>- 主题/表达手法/画风常规、常见，但执行到位 | - 内容空洞或明显抄袭，无情感或信息传递<br>- 主题/表达手法/画风常规且执行不到位；或创意佳但落地生涩（镜头混乱） |
| **叙事/结构完整性** | - 情节有清晰起承转合或情绪曲线（平静→冲突→解决→呼吁），开头结尾呼应<br>- 视频有高光点，镜头语言、景别景深恰当，服务情节<br>- 有独特隐喻、反讽或视觉符号，引发思考或共鸣 | - 情节有完整段落（开场-发展-结尾），但转折平淡，无情绪高潮<br>- 结构完整但无设计感，表达方式常见（如慢镜头），无新意 | - 片段化，无明确起承转合，或结尾突然中断<br>- 镜头语言、景别景深不当，节奏单一或混乱 |
| **稳定性和一致性** | - 无崩坏/瑕疵，AI增殖物，品牌Logo/文字清晰无乱码<br>- 产品/角色前后一致，光影符合物理逻辑 | - 轻微错误/AI增殖物（如背景微小扭曲），不影响品牌识别<br>- 产品/角色有微小变形（如边缘波浪），不影响认知 | - Logo文字乱码、品牌颜色错误、产品明显变形或前后不一致，光影错误<br>- 产品/角色明显崩坏、变形、场景瞬变 |

### 2.2 专业影视

#### 2.2.1 短片剧集

- **定义**：具有完整叙事结构（主角、任务、情节、动机、场景五要素）的虚构或非虚构类短篇影视作品，单集成片，强调起承转合与人物成长。
- **判定要点**：
  - 完整性：具备清晰主角（至少1个）、明确任务或目标、连贯情节（开端-发展-高潮-结局）、可理解动机、具体场景。
  - 内容形式/应用场景：虚构或非虚构类短篇叙事，单集独立或剧集形式，用于故事表达、电影节投递、剧情类账号运营等。
  - 写实：人物、环境、动作符合现实物理规律，光影自然，无卡通化或超现实扭曲（特殊叙事设计除外）。
  - 边界情况：若采用写实风格表现非人类角色（如动物、机器人）但包含明确故事线，仍归本类。

| 维度 | 优质 | 普通 | 低质（部分缺失） |
|------|------|------|------|
| **叙事/结构完整性** | 具备清晰五要素，有清晰故事线或起承转合，结局有情感或主题升华 | 五要素基本具备，但衔接平淡，无重大逻辑矛盾 | （未提供完整） |
| **角色一致性** | 主角行为深度契合动机，前后行为一致，符合人物发展逻辑 | 角色行为基本合理但单一 | （未提供） |
| **视听语言** | - 镜头语言：景别配置有层次变化，运镜与叙事意图关联，视点转换不混淆空间<br>- 构图与空间：主体位于视觉重心，视线方向留缓冲空间，景深与焦点匹配<br>- 光影色彩：主光源方向自洽，色温一致，肤色无明显偏移<br>- 剪辑节奏：节奏与叙事匹配，相邻镜头动作连续性良好，单镜头时长合理 | - 镜头语言：景别以中近景为主，运镜固定或简单推拉，少量视点跳跃但不致断裂<br>- 构图：主体大致居中或三分线，少量非预期背景元素，景深不随叙事调整<br>- 光影：均匀照明为主，色温轻微不一致，偶有过亮或过暗<br>- 剪辑节奏：变化幅度小，偶有动作匹配瑕疵，但叙事连贯 | （未提供） |
| **写实连贯性** | 时空转换自然，物理互动（碰撞、重力、遮挡）真实感强，人物动作丰富自然 | 偶尔有轻微穿帮（物品位置突变）但不影响理解 | （未提供） |
| **材质表现** | 皮肤、衣物、环境材质细节丰富且统一，场景光源固定，无明显穿帮 | 材质基本真实但缺乏细节 | （未提供） |
| **创意价值** | 主题新颖或对社会/人性有洞察，有令人印象深刻的台词或场景设计 | 主题常见，表达清晰但无惊喜 | （未提供） |

#### 2.2.2 风格美学、MV

- **定义**：以视觉风格、艺术实验、情绪氛围为核心（风格美学），或以音乐作品为驱动、画面与节奏同步诠释歌曲（MV）。弱化线性叙事，强调独特视听语言。
- **判定要点**：
  - **风格美学**：不要求五要素，以统一视觉主题或情绪曲线为“完整性”替代标准（如冷色调→暖色调渐变，或重复视觉符号）。内容形式用于艺术实验、品牌视觉、时尚展示等，允许抽象、超现实、卡通等非写实风格，但需审美一致性。写实则要求材质、光影真实。
  - **MV**：不要求五要素，但需音乐与画面完整对应（整首歌配画面，段落结构完整）。用于音乐发行、艺人宣传、KTV版等。可混合风格，写实类MV优先，非写实可单独标记。

| 维度 | 优质 | 普通 | 低质 |
|------|------|------|------|
| **视觉主题统一性** | - 风格美学：有清晰视觉符号或情绪曲线（由静至动、由冷到暖），开头结尾呼应；封面有画面感，能展示大致风格和主题 | - 风格一致但表现单调，无情绪变化<br>- MV：画面直接对应歌词字面意思，无深度 | （未提供） |
| **视听语言** | - 镜头语言精准，景别配置服务于音乐情绪与节奏，运动镜头与节奏/重音/旋律同步，视点转换增强流动感<br>- 构图与空间：主体与留白比例服务于整体风格，非常规构图（偏置、倾斜、裁切）有明确美学意图，景深与氛围匹配<br>- 光影色彩：有明确风格倾向（高对比、柔光、锐光、单色等），色调统一且与音乐情绪呼应，光影服务于造型<br>- 剪辑节奏：与音乐节奏、歌词、情绪呼应，镜头时长变化与音乐结构匹配 | - 镜头语言缺乏精准，景别变化但与音乐结构配合不够，运动镜头以基本推拉摇移为主，转换流畅但未增强节奏<br>- 构图以常规或对称为主，缺乏明确美学意图，景深设置常规<br>- 光影均匀，色调统一但无突出风格，无强烈情绪呼应<br>- 剪辑节奏基本匹配音乐，但无精心设计 | （未提供） |
| **写实/风格自洽** | - 若写实，光影质感真实；若非写实，光影质感模糊<br>- 人物动作准确 | - 写实风格有轻微失真但不违和<br>- 人物动作准确度一般 | （未提供） |
| **配乐质量** | - 配乐音质高，旋律吸引人，音质处理令人舒适 | - 旋律平淡或拖沓无亮点，音质处理无不适 | （未提供） |
