# Shimmy — 超轻量级开源 AI 推理服务器

## 概述

Shimmy 是一款超轻量级的开源 OpenAI API 推理服务器，仅 **5MB** 体积、**100ms** 启动，零配置、单二进制文件无依赖，定位为本地 AI 推理的高性价比方案，可替代 Ollama。

- **项目地址**: https://github.com/Michael-A-Kuykendall/shimmy
- **GitHub Star**: 3.8k+
- **许可证**: 永久免费
- **来源**: 微信公众号「牛码架构」

## 核心优势

| 特性 | 说明 |
|------|------|
| 极致轻量 | 仅 5MB 体积，100ms 启动，零配置 |

## 功能特性详解

### 接口兼容

提供 `/v1/chat/completions` 等 OpenAI 标准端点，可直接替代 OpenAI 服务端点，无缝接入 VS Code、Cursor 等开发工具。

### 模型管理

- 自动从 **Hugging Face 缓存**、**Ollama 模型目录**、**本地文件夹** 中发现 GGUF 模型
- 支持**运行时热交换**，无需重启服务
- 自动配置：自动发现模型、自动分配端口、自动启动服务

### 平台与硬件加速

- 全平台支持：Linux、macOS、Windows
- macOS 上支持 Apple Silicon 的 **Metal GPU 加速**
- 适用于 **Jetson Nano** 等边缘设备

### 部署方式

单二进制文件，无额外依赖，一条命令启动。支持 LoRA 适配器。

## 典型应用场景

1. **本地开发与测试** — 用小型模型本地运行，避免 OpenAI API 的成本和延迟，加速迭代
2. **隐私敏感应用** — 数据完全本地处理，不依赖云端，满足合规要求
3. **教育与研究** — 实验室服务器部署后，局域网多用户共享，降低模型访问门槛
4. **边缘设备部署** — 在 Jetson Nano 等资源受限设备上提供本地 AI 能力，无需联网
