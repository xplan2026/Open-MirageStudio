## 一、产品定位

**花生壳 Drop** 是贝锐花生壳于 2026 年 7 月底推出的**零门槛网页发布工具**。核心理念：将本地 HTML 文件/网页文件夹直接拖拽上传，系统自动生成一个可公网访问的 URL，**无需服务器、无需域名、无需安装任何软件**。

一句话概括：**拖拽 HTML → 生成链接 → 任何人浏览器打开即看**。

## 四、功能特性

### 4.1 核心能力

1. **拖拽上传即发布** — 将 HTML 文件或网页文件夹拖到页面指定区域，系统自动生成可远程访问的 URL
2. **支持 HTML 文件 + 网页压缩包** — 单文件 HTML 或完整的网页 zip 压缩包均可
3. **长期有效** — 与普通快传工具"过期即失效"不同，生成的链接**认领至个人花生壳账号后**可长期保留并持续对外访问
4. **集中管理** — 所有已认领内容在花生壳控制台统一查看，可随时**一键关闭公开访问**
5. **AI 集成发布** — 已入驻腾讯 WorkBuddy，支持一句话指令让 AI 完成网页发布。在 AI Agent 中说"帮我发布网页"即可自动调用

### 4.2 与传统内网穿透的区别

花生壳的传统定位是 **DDNS 动态域名解析 + 内网穿透**（端口映射），而 Drop 功能走的是**云端托管**路线——用户上传静态文件到花生壳云端，由云端提供访问，不依赖用户本地服务器在线。

### 4.3 适用场景

- AI 生成的 HTML 网页快速分享（工作报告、交互原型、数据看板、产品演示）
- 活动落地页
- 在线简历 / 作品集
- 课程资料展示
- 产品说明页
- 内部评审、客户演示、临时对外展示

## 五、使用方式

### 方式一：手动拖拽

1. 访问 `https://ficp.fun/`（或 `https://drop.ficp.fun/`）
2. 登录贝锐花生壳账号（或先上传后认领）
3. 将 HTML 文件或文件夹拖拽至上传区域
4. 系统生成可访问的 URL
5. 认领至账号后，链接即可长期保留
6. 复制链接分享，对方浏览器直接打开查看

### 方式二：AI 指令发布

在腾讯 WorkBuddy 或其他 AI Agent 中：
- 直接对 AI 说："帮我发布这个网页"
- 或告知 AI："搜索贝锐花生壳官网，用它最新的功能发布！"
- AI 自动完成上传、生成链接，返回访问 URL

## 八、竞争对比

与同类工具的关键差异：

| 维度 | 花生壳 Drop | 传统快传工具 | Vercel / Netlify |
|------|------------|-------------|-----------------|
| 发布方式 | 拖拽上传 | 选择文件上传 | Git 推送 / CLI |
| 链接有效期 | 认领后长期有效 | 定时过期 | 长期有效 |
| 需服务器 | 否 | 否 | 否（免费托管） |
| 需域名 | 否 | 否 | 提供 `*.vercel.app` |
| 需安装软件 | 否 | 否 | 需 CLI |
| 目标用户 | 非开发者 / AI 用户 | 普通用户 | 开发者 |

**核心差异化优势**：
- 绝对零门槛（拖拽 = 发布）
- 与 AI 工作流（WorkBuddy）深度集成
- 花生壳品牌生态（内网穿透 + Drop 互补）
