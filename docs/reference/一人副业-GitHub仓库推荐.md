## 一人副业真正的流程

绝大多数人理解的一人创业：
学技术 → 写代码 → 上线 → 赚钱

现实中的顺序：
**找案例 → 找痛点 → 做MVP → 接支付 → 上线发布 → 获取用户 → 持续迭代**

很多产品死掉，不是技术不行，而是：没需求、没用户、没分发能力。**研究成功案例，远比学习框架重要。**

---

## 10个仓库

### 1. awesome-one-person-company

中文圈最值得看的仓库之一。整理了大量真实的一人公司案例，包括产品做什么、用户是谁、收入多少、为什么成功/失败。很多项目公开了 MRR、获客渠道、成长路径和踩坑经验。

适合：想做副业/SaaS/AI 产品的程序员。

### 2. chinese-independent-developer

聚焦中国独立开发者都在做什么：AI工具、浏览器插件、微信生态、SEO工具、小工具站、导航站。能看到国内开发者真实的选择，很多项目已实现月入几千、几万乃至全职独立开发。

### 3. awesome-indie

全球 Indie Hacker 圈子最经典的资源库之一。内容包括：创业灵感、SaaS 方向、用户增长、SEO、邮件营销、自动化工具、支付方案。

### 4. awesome-indiehackers

偏向人和故事。包括独立开发者案例、收入复盘、产品分析、用户增长经验。看别人踩坑比看教程价值更高。

### 5. Best-Micro-SaaS-Tools

Micro SaaS 是最适合普通人的创业模式：用户群体小、需求明确、开发周期短、容易验证需求。典型案例：SEO 工具、数据监控、AI 小工具、自动化脚本、Chrome 插件。很多年收入百万的一人公司本质都是 Micro SaaS。

### 6. awesome-solo-founder-oss

解决"怎么做"的问题。包含：登录系统、支付系统、邮件系统、数据分析、用户管理、客服系统、增长工具。等于一人创业技术栈大全。

### 7. Open SaaS

目前最火的开源 SaaS 模板之一。直接提供：登录注册、Stripe 支付、邮件发送、后台管理、Landing Page、用户系统、权限管理。能节约几个月开发时间。

### 8. awesome-indie-hackers-tools

专门整理独立开发者工具：建站工具、数据分析、用户反馈、SEO、自动化、邮件营销、产品分析，覆盖整个运营周期。

### 9. awesome-launch-platforms

很多产品失败不是因为产品不好，而是没人知道。这个仓库整理了 Product Hunt、BetaList、Hacker News、Indie Hackers、Reddit 社区等产品发布平台。第一批用户很可能来自这些地方。

### 10. Awesome-SaaS-Directories

目录站是独立开发最容易获得 SEO 流量的地方，如 AI 工具目录、SaaS 导航站、产品分类站、软件推荐站。很多产品最初的几十个用户都来自目录站。

---

## 核心观点

真正能赚到钱的人做的是：**发现需求 → 快速验证 → 快速上线 → 获取用户反馈 → 持续迭代**。核心不是学了多少，而是做出来多少。
