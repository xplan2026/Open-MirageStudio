## 环境变量管理说明

本项目更名为 **mirage-studio**，每次打开 WebIDE 需手动添加以下环境变量文件：

| 文件 | 路径 | 内容 | 备注 |
|------|------|------|------|
| `.env` | `/workspace/.env` | CLOUDFLARE_*, CNB_*, SSH 私钥等 | Git 忽略，每次手动恢复 |
| `.env.codebuddy` | `/workspace/.codebuddy/.env.codebuddy` | 4C4G 服务器 SSH 配置 + 密钥 | Git 忽略，每次手动恢复 |

> 密钥文件统一存放在 `.codebuddy/ssh_keys/`（Git 忽略），由 `load-config.sh` 从 `.env.codebuddy` 自动提取。
