### 4. FamilyTree 三轮回合调试与修复

#### 第一回合：SVG viewBox 裁剪问题

**现象**：米家二代 6 人只显示 3 人（米南珍、米南发、米南芝），前 3 人不可见，无三代显示。

**原因**：D3 `tree().nodeSize()` 以 x=0 为中心排列子树节点。米福云 6 个子女以 200px 间距分布在约 x=−500 到 x=+500 范围，viewBox 从 (0,0) 开始 + margin.left=160px 平移，导致 x 为负的节点被 viewBox 裁剪。

**修复**：动态计算节点实际边界（minX/maxX/maxY），据此调整 group 平移量和 viewBox 尺寸。

#### 第二回合：坐标系统混淆

**现象**：一代（米福云）位置在右边三分之一处，后代仍然显示不全。

**原因**：修复第一回合时把纵向偏移（−minX）错误加到了横向位移（translate X），导致根节点跑到右侧。

D3 坐标对应关系：

| D3 | SVG | 含义 |
|-----|------|------|
| `d.y` | x（横轴） | 世代深度，左→右 |
| `d.x` | y（纵轴） | 兄弟姐妹排列，上→下 |

**修复**：横向保持 `margin.left` 不变，纵向用 `shiftY = -minX + margin.top` 来确保所有兄弟姐妹节点可见。

#### 第三回合：连线父节点错误

**现象**：所有成员的父系连线都指向米福云（根节点），而非各自的真实父节点。

**原因**：链接生成代码使用了全局 `source` 变量（`update(source)` 的参数，始终是根节点），而非每条连线自身的 `d.source`：

```javascript
// 错误：全局 source 变量（始终是根节点）
var sx = source.x0 != null ? source.x0 : d.source.x;

// 正确：每条连线自己的 d.source
return linkGen({ source: [d.source.y, d.source.x], ... });
```

这是一个经典的 D3.js 复制粘贴 bug，初学者常把全局 source 参数和每条数据的 source 属性混淆。

**修复**：直接使用 `d.source.y` / `d.source.x` 生成连线路径。

---

## 关键发现

1. **D3 tree 坐标系统**：`d3.tree().nodeSize()` 中 x 是纵向（兄弟姐妹排列）、y 是横向（世代深度）。对于水平布局的族谱树，需要手动交换坐标。
2. **D3 动画中的 source 陷阱**：`update(source)` 的参数是触发更新的节点，**不是**每条 link 的 source。生成 link path 时必须用 `d.source` 而非函数参数 `source`。
3. **SVG viewBox 边界计算**：使用 `nodeSize` 的树布局不会自动适配 viewBox，必须根据实际节点位置动态计算。
