## 关键发现

1. **服务器非 Docker 容器运行**，是通过 systemd user unit 直接运行的 Node 进程
2. **日志和镜像源工作区在 `/tmp/`**，系统重启后会丢失
3. **已有镜像源构建工作**，含 config/scripts/workspace
4. **多份配置备份**
