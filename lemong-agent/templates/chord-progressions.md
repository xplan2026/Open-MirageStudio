# 和弦走向参考库

>
> **最后更新**: 2026-07-14

---

## 字段说明

| 字段 | 说明 |
|------|------|
| **风格** | 关联的音乐风格 |
| **和弦** | 罗马数字级数表示（大小写区分大小和弦） |
| **调式示例** | 以 C 调为例的具体和弦 |
| **参考歌曲** | 使用该走向的经典歌曲 |
| **专业描述** | 走向的色彩/情绪/适用场景 |

> **罗马数字说明**: I=主和弦, ii=上主和弦, iii=中音和弦, IV=下属和弦, V=属和弦, vi=下中和弦, vii°=导和弦。大写=大和弦，小写=小和弦。
