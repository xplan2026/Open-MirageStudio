## 测试场景

创作一首以退役30年海军老兵（原驱逐舰109号）重回青岛舰队驻地为主题的歌曲：
- 风格：流行偏弱摇滚
- 歌手：二虎
- BPM：112，调式：小调→大调→小调
- 乐器：古典吉他为主，不要电音
- 核心情感：副歌体现30年后海军已强大，由内而生的自豪感

### 关键修复：DeepSeek 爱情歌词偏好

**问题**：DeepSeek-chat 对"歌词"一词有强烈的爱情主题偏好，无论 prompt 如何约束，均输出爱情题材。

**解决方案**：将 System Prompt 任务描述从「歌词创作」改为「现代诗创作」：
- 身份：`AI 音乐创作提示词工程师` → `现代诗诗人`
- 任务：`生成歌词 + 歌曲提示词` → `创作诗稿 + 配乐方案`
- 段落标注：`[主歌A]/[副歌]` → `[A段]/[B段]/[C段/高潮]`
- `歌手感知` → `朗诵者感知`

**效果**：成功绕过 DeepSeek 推理偏好，输出严格遵循用户指定主题。

> 详细实现见 `scripts/generate-prompt.js` 顶部注释。
