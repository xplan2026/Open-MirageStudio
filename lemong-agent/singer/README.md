# Lemong-Music 歌手目录

> 此目录存放预定义的歌手 Profile，每个歌手一个子文件夹。
> 在歌曲创作流程中，可选择预定义歌手来影响人声风格和音乐风格生成。

## 目录结构

```
singer/
├── README.md              # 本文件
├── 二虎/
│   ├── profile.json       # 歌手 Profile（必选）
│   └── sample.mp3         # 声音采样文件（可选，暂缺）
└── {未来歌手名}/
    ├── profile.json
    └── sample.mp3
```

## 歌手 Profile 规范

每个歌手的 `profile.json` 包含以下字段：

| 字段 | 说明 | 必填 |
|------|------|------|
| `name` | 歌手名称 | ✅ |
| `voice_characteristics` | 声音特征描述（音色、风格、音域、技巧等） | ✅ |
| `music_style` | 擅长音乐风格（类型、典型乐器、BPM 范围、情绪关键词） | ✅ |
| `artistic_identity` | 个人音乐特征（主题定位、歌词主题、形象描述） | ✅ |
| `audio_samples` | 声音采样文件信息 | 可选 |
| `usage_in_prompt` | 在提示词生成中如何注入歌手特征 | ✅ |

## 使用方式

在歌曲创作流程的阶段一（信息收集）中，会询问用户是否选择预定义歌手：

- **选择歌手**: 歌手的声线特征、音乐风格偏好会注入到 LLM 提示词中
- **不选择（默认）**: 系统按模板中的通用人声风格问题收集偏好

## 添加新歌手

1. 在 `singer/` 下创建以歌手名命名的子目录
2. 创建 `profile.json`，按上述规范填写
3. 如有声音采样文件，放入同目录下命名为 `sample.mp3`
