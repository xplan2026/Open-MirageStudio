## 关键决策记录

### "现代诗创作"策略

- **日期**: 2026-07-15
- **问题**: DeepSeek-chat 对"歌词"一词有强烈的爱情主题偏好
- **决策**: 将 System Prompt 任务从"歌词创作"改为"现代诗创作"
  - 身份: `AI 音乐创作提示词工程师` → `现代诗诗人`
  - 段落标注: `[主歌A]/[副歌]` → `[A段]/[B段]/[C段/高潮]`
- **效果**: 成功绕过 DeepSeek 推理偏好，输出严格遵循用户指定主题

### 双轨制设计决策（模板 vs 硬编码）

- **日期**: 2026-07-14
- **问题**: `generate-music.js` 中的 `STYLE_TEMPLATES` 硬编码与 `templates/` 问卷并行
- **决策**: 保留双轨制
  - 交互式路径: 通过模板问卷 + LLM 生成定制化 `music_prompt`（精细控制）
  - 快捷路径: CLI `--style` 直接使用预设高质量 prompt（快速生成）
- **理由**: 两者互补而非冗余，面向不同使用场景
